# 디자인 적용 결과 & 디자이너 확인 요청

몬스터 클래스 아트북 v0.2를 게임에 적용한 결과입니다. 그림 파일 자체는 수정하지 않았습니다(`design/` 폴더는 그대로).

## 적용한 것
- 유닛 스프라이트(걷기 2 + 공격 2 프레임, 파랑/빨강), 타워, 전장·메뉴 배경, 버튼 4종(눌림 포함), 대화 상자, 폭발·배치 마법진·투사체 이펙트, 앱 아이콘.
- 카드 PNG 위에 글자 올림: 잉크 방울에 코스트(주아), 리본에 이름(고운바탕 Bold, 길면 자동 축소).
- 폰트 4종(Google Fonts): 고운바탕(제목·카드 이름), 주아(숫자·버튼), 개구(안내 문구), 고운돋움(본문).
- 카드 표시 이름 변경 (id는 그대로): 포크창 도깨비, 새총 쌍둥이, 책가방 골렘, 시험지 박쥐 떼, 플라스크 슬라임, 해골 선도부, 용 선생 재채기, 급식 투석기.
- 게임 내 용어를 아트북에 맞춤: 마나 → 잉크, 기숙사 태그(달빛관 · 나 / 노을관 · 상대), 양피지 타이머.

## 카드 구성 (23장)
- 기존 8장 + 새 카드 15장. 새 카드 42장 중 **지금 규칙(근접·원거리·공중·범위·건물)으로 동작하는 카드만** 넣었습니다.
- 기존에 개발 쪽에서 임시로 추가했던 5장은 역할이 같은 아트북 카드로 교체: 화살비→깃펜 소나기, 수호 포탑→촛대 감시탑, 화염 마법사→견습 마법사 냥냥, 돌격 기병→호박 기사, 꼬마 도깨비→버섯 요정단.
- 새로 넣은 카드: 견습 마법사 냥냥, 호박 기사, 버섯 요정단, 깃펜 소나기, 촛대 감시탑, 빗자루 부엉이, 촛불 유령, 젤리곰 반장, 수정 거북, 불도마뱀 조교, 아기 드래곤 꾸벅, 개구리 왕자, 꿀벌 우편대, 마법 첨탑, 말하는 나무.
- 나머지 27장(회복·빙결·감속·시간 정지·변신·소환·잉크 생성·순간이동·은신·흡혈·연쇄·광폭·끌어당기기·돌진 등)은 능력 시스템을 만든 뒤 다음 단계에서 추가합니다.
- 수치는 아트북의 체력/공격/속도 막대와 코스트를 기준으로 정하고, 1:1 대결 시뮬레이션으로 튀는 카드를 조정했습니다(`npx tsx shared/scripts/balance.ts`).

## 새 카드 스프라이트
아트북에 전장용 시트가 기존 8장만 있어서, 새 카드 14장의 시트는 **디자이너의 `design/art.js`로 같은 규격(걷기2+공격2, 2배 크기)으로 직접 뽑았습니다** (`node client/scripts/build-assets.mjs`). 그림은 art.js 그대로이고, 크기만 게임 표시 크기에 맞췄습니다.

## 확인 요청 (그림 수정이 필요한 것)

### 1. 팀 색이 없는 캐릭터 10종 — 우선순위 높음
아래 캐릭터는 art.js에서 파랑/빨강 버전이 **완전히 같은 그림**으로 나옵니다. 전투 중 아군/적 구분이 안 돼서, 지금은 임시로 발밑에 팀 색 고리를 그려 두었습니다. 기존 8장처럼 로브·목도리·리본 등에 팀 색을 넣어 주세요.
- 꿀벌 우편대(beeMail), 빗자루 부엉이(broomOwl), 촛불 유령(candleGhost), 수정 거북(crystalTurtle), 개구리 왕자(frogPrince), 젤리곰 반장(jellyBear), 버섯 요정단(mushroomTrio), 호박 기사(pumpkinKnight), 불도마뱀 조교(salamander), 아기 드래곤 꾸벅(sleepyDragon)
- 건물(촛대 감시탑·마법 첨탑·말하는 나무)과 견습 마법사 냥냥은 팀 색이 들어가 있습니다.

### 3. 전장 배경의 강·다리 폭 (작은 차이)
- 게임 판정: 강은 32칸 중 15~17칸(2칸 높이), 다리는 중심 x=3.5 / 14.5에서 폭 2칸.
- 배경 그림: 강이 약 14.6~17.4칸, 다리 바닥이 약 2.4칸 폭으로 조금 넓습니다. 유닛이 다리 가장자리를 걸을 때 살짝 물 위처럼 보일 수 있어요. 강 높이를 2칸(160px, 원본 기준 y 1200~1360), 다리 바닥 폭을 2칸(160px)에 맞춰 주시면 정확히 겹칩니다.

### 4. 용량
- 게임이 불러오는 그림은 약 4.4MB(카드 23장 기준). 그중 `bg/arena.png`가 750KB로 가장 큽니다. 무늬가 단순하니 색 수를 줄인 PNG나 WebP로 줄일 수 있으면 첫 로딩이 빨라집니다.

### 5. 작은 것
- 기권 버튼: 1080×210 비율 그대로 줄이면 손가락으로 누르기엔 너무 얇아서(약 16px), 게임에서는 140×56으로 늘려 씁니다. 작은 버튼용 비율(예: 360×140) 이미지가 있으면 더 깔끔합니다.
