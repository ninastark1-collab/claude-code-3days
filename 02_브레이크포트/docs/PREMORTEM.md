# Break Fort 프리모템 — "출시 3개월 후 망했다면, 왜?"

출시 후 실패했다고 가정하고 원인을 거꾸로 짚어 본 문서. 디자인(그래픽)은 별도 진행 중이라 제외하고, **게임 자체**만 다룸.
근거: 카드 1:1 대결 시뮬레이션(`npx tsx shared/scripts/balance.ts`), 봇 대 봇 경기 통계, 코드 검토.

## 판정 요약

| # | 실패 원인 (가설) | 심각도 | 근거 | 조치 |
|---|---|---|---|---|
| 1 | **밸런스 붕괴: 박쥐 떼 한 장이 메타를 지배** | 치명 | 비용 대비 점수 21.0(2위 13.3). 공중을 칠 수 있는 유닛이 7장 중 석궁수 1장뿐이라 박쥐가 거의 모든 카드를 무피해로 이김 | 이번에 수정 |
| 2 | **약한 카드는 아무도 안 씀** (창병·투석 포대) | 높음 | 창병 점수 −7.8(전패 수준), 투석 포대는 타워에 피해 0 | 이번에 수정 |
| 3 | **덱이 모두 똑같음 → 전략이 없음** | 치명 | 8장 고정 덱. 덱 구성이 장르의 핵심 재미인데 선택지가 0 | 이번에 수정 (카드 13장 + 덱 편집) |
| 4 | **빠른 매칭에 아무도 없음 (초기 유저 부족)** | 치명 | 출시 초기 동시 접속자가 적으면 대기 화면에서 이탈. 지금은 무한 대기 | 이번에 수정 (15초 후 AI 상대) |
| 5 | **처음 하는 사람이 규칙을 모름** | 높음 | 튜토리얼·카드 설명 없음. 마나, 배치 구역, 상성(공중/지상)을 알 방법이 없음 | 이번에 수정 (카드 정보, 첫 판 안내) |
| 6 | **계속할 이유가 없음 (성장 요소 0)** | 높음 | 트로피·전적·등급이 없어 몇 판 하고 끝 | 이번에 수정 (트로피·등급·전적) |
| 7 | 연습 봇이 한 난이도뿐 | 중간 | 초보에겐 어렵고 숙련자에겐 시시함 | 이번에 수정 (쉬움/보통/어려움) |
| 8 | 메시지 폭주로 서버 공격 가능 | 중간 | 초당 메시지 제한 없음 | 이번에 수정 |
| 9 | 기사단이 혼자서 타워 하나를 통째로 파괴 | 중간 | 5마나로 1800 피해(방어 없을 때) — 탱커 역할인 방패 거인과 동급 | 이번에 수정 |
| 10 | 기록이 기기에만 저장 → 조작·분실 가능 | 높음(출시 시) | 계정/서버 DB 없음 | 다음 단계: 계정 + 서버 저장 |
| 11 | 실력별 매칭 없음 | 중간 | 트로피와 무관하게 매칭 | 다음 단계: 유저가 늘면 트로피 구간 매칭 |
| 12 | 상대와 소통 수단 없음(이모트) | 낮음 | 장르에서 재미 요소지만 핵심은 아님 | 다음 단계 |
| 13 | 서버 1대 구성, 모니터링·통계 없음 | 중간(출시 시) | 장애·밸런스 데이터를 볼 수 없음 | 6단계(배포)에서 |

## 밸런스 측정 방법
`npx tsx shared/scripts/balance.ts` — 모든 카드 쌍을 같은 라인(다리 앞)에서 1:1로 싸움 붙임(타워 없음).
- **원점수**: 이기면 +(1+남은 체력), 지면 −. 비싼 카드를 이기면 가산, 비싼 카드에 지면 감점을 줄임.
- **공정 점수**: "아예 때릴 수 없는" 상성(지상 전용 vs 비행, 건물만 노리는 거인)을 뺀 점수. 의도된 상성을 빼고 순수한 비용 대비 효율을 봄.
- 처음 측정본에는 배치 위치·가중치 오류가 있어, 아래 "수정 전" 수치는 고친 스크립트로 이전 카드 데이터를 다시 측정한 값.

## 변경 결과

### 카드 수치 (수정 전 → 후)
| 카드 | 변경 | 이유 |
|---|---|---|
| 박쥐 떼 | 공격 60→40, 체력 80→60 | 타워 한 발에 한 마리씩 처리되도록 |
| 창병 | 체력 700→760, 공격 120→130, 사거리 0.8→1.2, **공중 공격 가능** | 거의 전패 → 대공 겸용 기본 병사로 |
| 석궁수 | 공격 90→75, 체력 250→280 | 대공 독점이 풀려 공격력은 낮추고 생존력 보강 |
| 기사단 | 체력 550→450, 공격 110→95 | 혼자 타워 1개를 부수던 문제 (1800 → 1425 피해) |
| 투석 포대 | 체력 900→1100, 사거리 6.5→7, 범위 공격 추가, 공격 140 | 수비 효율이 너무 낮음 |
| 연장전 마나 | 2배 → 3배 | 교착 상태를 깨기 위한 장치 |

### 새 카드 5장 (총 13장, 덱은 8장 선택)
화염 마법사(5, 범위·대공), 화살비(3, 주문), 돌격 기병(4), 수호 포탑(3, 건물), 꼬마 도깨비(2).

### 측정 결과
| | 수정 전 | 수정 후 |
|---|---|---|
| 공중을 칠 수 있는 유닛 | 1장 (석궁수) | 3장 (창병·석궁수·화염 마법사) + 주문 2장 |
| 공정 점수 범위 (박쥐 제외) | −2.8 ~ +4.5 (7장) | −6.6 ~ +6.1 (11장) |
| 창병 원점수 | −1.84 | +4.86 |
| 박쥐 원점수 | 19.75 | 23.79 |

- 박쥐 원점수는 오히려 조금 올랐는데, 지상 전용 카드가 늘어 "때릴 수 없는 상대"를 이기는 경우가 많아졌기 때문. 반면 **카운터가 1장 → 5장**으로 늘어 덱만 맞추면 쉽게 막을 수 있게 됨. 덱 편집 화면은 공중 대응 카드가 없으면 경고를 띄움.
- 꼬마 도깨비(−6.6)는 1:1 싸움용이 아니라 시간 끌기·견제용이라 낮게 나옴. 실제 대전 데이터를 보고 조정 필요.

### 봇 대 봇 (30경기 × 2)
타워가 하나라도 부서진 경기 비율: 기본 덱 27~30%, 무작위 덱 27~37% (수정 전 약 40%). 수치 조정(연장전 마나 3배, 보조 타워 체력 1500 실험)으로는 거의 변하지 않아, 원인은 규칙보다 **봇의 공격 방식**(한 장씩 투입)으로 판단. 보조 타워 체력은 근거가 없어 1800으로 되돌림. 사람 대 사람 경기 데이터로 다시 확인할 것.

### 이번에 들어간 기능
- 덱 편집 (13장 중 8장, 평균 마나·공중 대응 경고, 카드별 능력치 설명). 서버가 덱을 검증하고, 잘못된 덱은 기본 덱으로 대체.
- 빠른 매칭 15초 후 AI 상대 배정 (화면에 "AI 상대" 표시, 트로피 절반).
- 트로피·등급(견습 병사 → 전설의 요새)·전적·연승 표시, 결과 화면에 트로피 변화.
- 첫 연습 경기 안내 문구 5단계, 카드 길게 누르면 능력치 보기.
- 연습 봇 난이도 3단계 (쉬움/보통/어려움), 봇이 공중 유닛에는 대공 카드로 대응.
- 서버 초당 메시지 20개 제한.

### 남은 위험 (다음 단계)
- 트로피·덱이 기기에만 저장됨 → 계정·서버 저장 필요 (조작·분실 위험).
- 실력별 매칭 없음, 이모트 없음, 운영 모니터링 없음.
- 밸런스는 시뮬레이션 기준. 실제 유저 경기 통계(카드 사용률·승률)를 모으는 장치가 필요.
