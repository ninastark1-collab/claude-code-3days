그림 규칙

모든 몬스터가 지키는 다섯 가지

2등신, 큰 눈

머리와 몸통이 한 덩어리. 눈은 얼굴 폭의 1/3 이상, 흰자에 하이라이트 점 하나.

보라 외곽선 4px

128px 기준 외곽선 4px, 색은 언제나 #2A2350. 음영은 단색 1단계만 넣어서 스티커처럼 보이게 합니다.

학교 소품 하나

무기 대신 학교 물건을 듭니다. 포크, 새총, 책가방, 자, 플라스크. 실루엣만 봐도 누군지 알 수 있어야 합니다.

팀 색은 발판으로

유닛 그림은 두 팀이 같습니다. 팀은 발밑 타원 발판과 체력 바 색으로만 구분합니다.

차별화

하기: 평면 벡터, 스티커 질감, 학교 소재.
피하기: 광택 있는 3D, 왕·기사·고블린 같은 정통 판타지 외형, 금속 테두리 UI.

카드 8종 · 학생증

우리 반 친구들

카드 하나가 학생증 한 장입니다. 수치는 지금의 cards.json 값을 그대로 썼고, 바뀌는 건 이름과 그림뿐입니다. 테두리 색이 희귀도를 나타냅니다.

희귀도

분필 · 잉크 · 금박 · 별빛

희귀도 이름도 학교 문구류에서 가져왔습니다. 같은 카드라도 테두리만 바꾸면 등급이 달라 보이도록 프레임은 하나로 통일했습니다.

전장

밤의 운동장

18×32 타일 그리드와 강·다리·타워 좌표는 지금 코드 그대로입니다. 바닥에는 분필로 그린 운동장 선을 깔고, 강은 잉크 개울로, 다리는 펼친 책으로 바꿉니다.

기숙사 종탑 (메인)지름 3타일. 지붕은 팀 색, 금빛 종이 공격할 때 흔들립니다. 파괴되면 종이 떨어지며 책 더미로 무너집니다.
등불 탑 (사이드)지름 2.2타일. 등불에서 도깨비불 투사체를 쏩니다.
책 다리폭 2타일. 왼쪽은 빨간 표지, 오른쪽은 남색 표지로 레인을 구분합니다.
잉크 개울2타일 폭. 물결 2줄이 천천히 흐르고 반짝이 점이 깜빡입니다.
분필 배치 원배치 대기 1초 동안 원이 그려지고, 유닛은 반투명으로 보입니다.

전투 HUD 규칙

손패 4장과 다음 카드 1장. 잉크가 모자란 카드는 채도를 낮춥니다. 선택한 카드는 6px 위로 뜨고 금박 외곽선을 두릅니다. 타이머는 종이 메모처럼 살짝 기울여 붙이고, 남은 1분(잉크 2배 구간)에는 메모가 보라색으로 바뀌며 흔들립니다.

수집

학생부를 채우는 재미

카드 레벨은 학년, 조각은 출석 도장, 도감은 학생부입니다. 학교라는 테마 하나로 수집 시스템 전체를 설명할 수 있습니다.

학년 = 레벨

1학년에서 6학년까지. 학년이 오를 때마다 학생증 사진 옆 학년 표시가 바뀌고, 6학년이 되면 사진에 졸업 모자가 씌워집니다.

123456 · 졸업

출석 도장 = 카드 조각

중복 카드는 출석 도장으로 바뀝니다. 도장 칸을 다 채우면 진급할 수 있습니다.

포크 도깨비 · 2학년 → 3학년 · 7 / 10

학생부 = 도감

아직 못 만난 학생은 실루엣으로만 보입니다. 다음 업데이트 후보를 미리 보여 주며 수집 욕구를 끌어올립니다.

연출

움직임 메모

배치분필 원이 0.3초 동안 그려지고, 펑 하는 분필 가루와 함께 유닛이 통통 튀며 착지합니다.
대기 모션모든 유닛은 1.2초 주기로 몸을 위아래 4% 늘였다 줄입니다. 박쥐는 종이처럼 팔랑입니다.
피격흰색으로 0.06초 번쩍인 뒤 좌우로 살짝 흔들립니다. 숫자는 띄우지 않고 체력 바만 줄어듭니다.
용 선생 재채기화면이 0.2초 흔들리고 “에취!” 손글씨가 터지며 주황 불꽃 원이 퍼집니다.
타워 파괴종이 “땡” 하고 떨어지며 탑이 책 더미로 무너집니다. 화면 위쪽에 상점 도장이 쾅 찍힙니다.
잉크 2배잉크 개울이 더 빨리 흐르고 마나 바에 반짝이가 흐릅니다.

개발자 전달

적용 가이드

게임 로직과 카드 id는 바꾸지 않습니다. 색 상수와 표시 이름, 그림만 교체하면 됩니다. 희귀도는 cards.json에 rarity 필드를 하나 추가하는 방식을 제안합니다.

// client/src/layout.ts
export const COLORS = {
  me:        0x4f8bff, // 달빛 블루
  enemy:     0xff6b4a, // 노을 코랄
  grass:     0x7dbe5a,
  grassDark: 0x74b452,
  river:     0x5b34c7, // 잉크 개울
  riverWave: 0x8b6bf0,
  bridge:    0xf6e7c8, // 책 종이
  ui:        0x23453f, // 칠판
  uiFrame:   0x8c5e3c, // 나무 틀
  mana:      0x7b4be0, // 잉크
  outline:   0x2a2350, // 0x000000 / 0x111111 대체
  chalk:     0xf3efe6,
  gold:      0xffc94a, // 선택, 0xffd166 대체
};

export const RARITY = {
  chalk: 0xd9d4c7, // 분필
  ink:   0x3fb7c9, // 잉크
  gold:  0xffc94a, // 금박
  star:  0xc9a0ff, // 별빛 (홀로그램 셰이더)
};

export const FONT =
  "'Jua', 'Gowun Dodum', 'Malgun Gothic', sans-serif";
// index.html에 Google Fonts: Jua, Gaegu, Gowun Dodum
