## 1. 핵심 원칙

| 원칙 | 내용 |
|---|---|
| **개입 없음** | 작전을 확정하면 전투가 끝날 때까지 플레이어는 손댈 수 없다. 예외 없음 |
| **결정은 전부 앞에** | 대신 작전 회의에서 고를 것이 충분히 많아야 한다. 전투의 재미는 "작전을 짜는 시간"과 "내 작전이 맞아떨어지는 걸 보는 시간"에서 나온다 |
| **정답 없는 상성** | 모든 방침에는 강한 상대와 약한 상대가 있다. 무조건 이기는 방침은 없다 |
| **장수가 작전을 수행한다** | 같은 작전도 누가 맡느냐에 따라 결과가 다르다. 지력이 낮거나 오만한 장수는 작전을 어길 수 있다 |
| **결과는 설명 가능해야** | 지거나 이겼을 때 "왜 그랬는지"를 보고서로 알 수 있어야 한다. 그래야 다음 작전이 나아진다 |

> 축구 매니지먼트 게임은 "구조"만 참고한다. 화면 구성, 용어, UI는 삼국지 분위기에 맞게 새로 만든다 (설계노트 40장 독창성 원칙).

## 2. 전투 흐름

```
[전투 발생]
   ↓
① 정찰 보고 ─── 적 병력·병종·장수·배치를 정찰 수준만큼 공개 (9장)
   ↓
② 군사 진언 ─── 군사가 적의 방침을 예측하고 추천 작전을 제시
   ↓
③ 작전 회의 ─── 전군 방침 → 부대 배치(역할) → 부대별 설정 → 조건 명령
   ↓              화면 한쪽에 "예상 승률"과 "주의 사항" 표시
④ 작전 확정 ─── 되돌릴 수 없음 (확인창 1회)
   ↓
⑤ 자동 전투 ─── 관전 또는 결과만 보기 (10장, 11장)
   ↓
⑥ 결과 보고서 ── 승패, 피해, MVP, 적 방침 공개, 군사 총평 (12장)
```

- 공격 측과 방어 측 모두 같은 절차를 거친다. AI도 같은 규칙으로 작전을 짠다.
- **결과만 보기**를 고르면 ⑤를 건너뛰고 바로 ⑥으로 간다. 작은 전투를 빨리 넘길 때 쓴다.
- **위임 작전**: 작전 회의 자체를 군사에게 맡기는 버튼. 군사 지력이 높을수록 좋은 작전을 짠다.

## 3. 작전 회의: 입력의 3단 구조

입력이 많으면 피곤하고, 적으면 단순하다. 그래서 **위에서 아래로 내려가는 3단 구조**로 만든다. 1단만 정해도 전투가 가능하고, 고수는 3단까지 손댄다.

| 단계 | 정하는 것 | 필수 여부 | 초보 | 고수 |
|---|---|---|---|---|
| 1단 | **전군 방침** (4·5장에서 1개) | 필수 | 이것만 고르면 나머지는 자동 배정 | |
| 2단 | **부대 배치와 역할** (7-1) | 선택 (자동 배정 가능) | | 누구를 선봉에, 누구를 매복에 |
| 3단 | **부대별 세부 설정 + 조건 명령** (7-2~7-6, 8장) | 선택 | | 태도, 진형, 목표, 퇴각 기준, if-then 명령 |

- 1단을 고르면 2단과 3단은 **그 방침에 맞는 기본값**으로 채워진다. 플레이어는 바꾸고 싶은 것만 바꾸면 된다.
- 마지막 작전을 저장해 두는 **작전 프리셋** (예: "내 기병 포위 작전") 기능을 둔다.

## 4. 공격 방침 14종

| # | 방침 | 내용 | 필요 조건 | 강한 상대 | 약한 상대 |
|---|---|---|---|---|---|
| A1 | **정면 돌파** | 전군이 정면으로 전진해 맞붙는다 | 없음 | 지연전, 질서 퇴각 | 견고 수비, 매복 요격, 유인 역습 |
| A2 | **학익 포위** | 양익이 크게 돌아 적을 감싼다 | 부대 3개 이상, 기병이 있으면 효과 ↑ | 견고 수비, 종심 방어 | 선제 출격, 매복 요격 |
| A3 | **추행 돌파** | 정예를 쐐기처럼 모아 적 중앙을 가른다 | 무력·통솔 높은 선봉 | 견고 수비, 선제 출격 | 종심 방어, 유인 역습 |
| A4 | **성동격서** | 일부가 한쪽을 치는 척하고 주력이 반대쪽을 친다 | 총대장 또는 군사 지력 70+ | 견고 수비, 종심 방어, 유인 역습 | 선제 출격, 적 지휘관이 냉정·신중일 때 |
| A5 | **유인 매복** | 약한 부대가 패주하는 척하며 적을 매복지로 끌어들인다 | 숲·산·갈대 지형, 매복대 지정 | 선제 출격, 배수진 | 견고 수비 (따라오지 않음), 지연전 |
| A6 | **화공 작전** | 바람과 지형을 이용해 적 진영에 불을 지른다 | 맑음 + 바람, 연료 지형, 화공 가능 장수 | 견고 수비, 종심 방어, 유인 역습, 매복 요격, 농성(진채) | 선제 출격, 지연전, 비, 산개 대형 |
| A7 | **야습** | 밤에 기습해 적을 혼란에 빠뜨린다 | 전투를 밤에 시작 (출진 시 선택), 정찰 1 이상 | 견고 수비, 지연전 | 경계 태세, 매복 요격, 신중한 적장 |
| A8 | **참수 작전** | 정예 기병이 우회해 적 총대장을 직접 노린다 | 무력 85+ 장수의 기병 부대 | 적 총대장이 약할 때, 종심 방어 | 본진 철벽, 매복 요격 |
| A9 | **소모전** | 원거리 공격 위주로 근접을 피하며 적의 병력과 사기를 깎는다 | 궁병·노병 비중 높음, 병량 여유 | 견고 수비, 농성 | 선제 출격, 기병 위주 적 |
| A10 | **질풍 속공** | 적이 진형을 갖추기 전에 기병으로 휩쓴다 | 기병 비중 50%+ | 지연전, 화공 역습 준비 | 창병 위주 적, 종심 방어 |
| A11 | **보급 차단** | 별동대가 적의 보급 거점을 쳐서 병량을 끊는다 | 별동대 1개 이상, 장기전 각오 | 농성, 지연전, 장기전 전반 | 질풍 같은 단기 결전 상대, 선제 출격 |
| A12 | **도발전** | 무력 높은 장수가 적장을 연이어 도발해 일기토를 유도한다 | 무력 90+ 장수 | 호걸·오만한 적장 다수 | 냉정한 적장, 원거리 위주 적 |
| A13 | **사면 공성** | 성을 사방에서 포위하고 성벽 여러 곳을 동시에 친다 | 공성전 전용, 병력 3배 이상 권장 | 수비 병력이 적은 성 | 출격 요격, 원군 |
| A14 | **성문 집중** | 공성 병기를 성문 하나에 몰아 빠르게 돌파한다 | 공성전 전용, 공성 병기 | 성벽이 높은 성 | 성문 방어 강화, 화공 역습 |

※ 공성전에서는 A13, A14 외에 A6 화공, A9 소모전, A11 보급 차단도 선택 가능.
※ 사전 첩보로 **내응 공작**(설계노트 7-2)에 성공해 두면 공성전에서 "내응 연계" 옵션이 추가된다.

| 기호 | 보정 |

### 6-3. 원칙
- 상성은 **결정이 아니라 보정**이다. 병력이 2배 차이 나거나 능력치 차이가 크면 상성으로 뒤집기 어렵다. 상성으로 뒤집을 수 있는 건 대략 **전력 차 30% 이내**.
- 상성은 **방침이 제대로 실행됐을 때만** 적용된다 (10-3 실행도). 지력 낮은 장수가 성동격서를 고르면 엉성하게 실행되어 보정이 줄거나 오히려 역효과가 난다.
- 나머지 방침의 상성은 4·5장 표의 "강한 상대 / 약한 상대" 열을 기준으로 개발 데이터에 넣는다 (14장).

## 7. 부대 단위 설정

### 7-1. 역할 (배치)
| 역할 | 기본 행동 | 어울리는 장수 |
|---|---|---|
| 선봉 | 가장 먼저 적과 맞붙는다 | 무력·통솔 높음 |
| 중군 | 주력. 선봉 뒤에서 본격 교전 | 통솔 높음 |
| 좌익 / 우익 | 측면 담당. 포위·우회의 핵심 | 기병, 기동력 |
| 후군 (예비대) | 처음엔 대기, 조건 명령이나 방침에 따라 투입 | 균형형 |
| 본진 | 총대장 부대. 지휘 범위의 중심 | 총대장 |
| 궁노대 | 뒤에서 원거리 지원 | 궁병·노병 |
| 매복대 | 지정 지형에 숨어 있다가 발동 | 지력 높은 장수 |
| 유격대 / 별동대 | 우회, 보급 차단, 참수 작전 | 기병, 무력 높음 |
| 공성대 | 공성 병기 운용 | 공성전 전용 |

### 7-2. 태도 (5단계)
| 태도 | 행동 |
|---|---|
| 맹공 | 피해를 감수하고 공격. 공격 +15%, 방어 -15% |
| 공격 | 적극 교전 |
| 균형 | 기본 |
| 신중 | 유리할 때만 교전. 방어 +10%, 공격 -10% |
| 사수 | 지정 위치를 끝까지 지킨다. 이동 안 함 |

### 7-3. 진형
| 진형 | 강점 | 약점 |
|---|---|---|
| 방원진 | 사방 방어, 포위에 강함 | 공격력 ↓ |
| 어린진 | 정면 돌파력 ↑ | 측면 취약 |
| 학익진 | 포위 효율 ↑ | 중앙 얇음 |
| 장사진 | 이동 속도 ↑ | 교전 시 불리 |
| 방진 | 기병 돌격에 매우 강함 (창병) | 이동 느림 |
| 산개 | 화공·원거리 피해 ↓ | 근접 교전 약함 |

- 진형은 장수가 **익힌 것만** 쓸 수 있다 (장수 데이터에 습득 진형 목록).

### 7-4. 목표 우선순위
가장 가까운 적 / 가장 약한 적 / 원거리 부대 / 기병 / 공성 병기 / 적 총대장 / **지정 장수** (예: "여포 부대만 상대하지 말고 피해라"처럼 회피 목표도 지정 가능)

### 7-5. 계략과 일기토 방침
| 항목 | 선택지 |
|---|---|
| 계략 사용 | 적극 / 기회가 오면 / 아낌 (위기 때만) / 금지 |
| 선호 계략 | 화계, 혼란, 위보, 고무 등 중 최대 2개 |
| 일기토 | 적극 신청 / 신청받으면 수락 / 모두 거절 / 특정 장수에게만 신청 |

### 7-6. 퇴각 기준
- 병력 몇 % 이하, 또는 사기 몇 이하가 되면 스스로 퇴각
- "퇴각 금지"도 가능 (배수진 방침이면 자동으로 금지)
- 신중 성격 장수는 기준보다 조금 일찍, 호걸·오만 장수는 조금 늦게 퇴각

## 8. 조건 명령: 자동 전투에 깊이를 주는 핵심

전투 중에 개입할 수 없으니, **"이런 일이 생기면 이렇게 하라"**를 미리 정해 둔다. 이것이 단순한 자동 전투와 이 게임을 가르는 핵심이다.

### 8-1. 슬롯 수
| 범위 | 슬롯 |
|---|---|
| 전군 조건 명령 | 기본 1개 + 총대장 통솔 70+ 이면 1개 + 군사 지력 80+ 이면 1개 (최대 3개) |
| 부대별 조건 명령 | 부대 장수 지력 60+ 이면 1개 |

→ 뛰어난 총대장과 군사가 있어야 복잡한 작전을 짤 수 있다. **인재의 가치가 전투에서 그대로 드러난다.**

### 8-2. 조건 목록
| 분류 | 조건 |
|---|---|
| 시간 | 전투 N턴 경과 / 밤이 되면 / 낮이 되면 |
| 아군 상태 | 아군 [부대] 병력 N% 이하 / 아군 전체 사기 N 이하 / 아군 장수가 일기토에서 패배 |
| 적 상태 | 적 사기 N 이하 / 적 퇴각 시작 / 적 총대장 위치 노출 / 적 기병 돌격 감지 |
| 위치 | 적이 [지점]에 진입 (매복지, 다리, 성문 앞) / 적 본진이 [거리] 이내 |
| 환경 | 바람이 [방향]으로 바뀜 / 비가 오기 시작 / 비가 그침 |
| 공성 | 성문 파괴 / 성벽 돌파 / 원군 도착 |

### 8-3. 행동 목록
| 분류 | 행동 |
|---|---|
| 투입 | 예비대 투입 / 매복 발동 / 별동대 출발 |
| 전환 | 태도 변경 / 진형 변경 / 목표 변경 / 전군 방침 2단계로 전환 |
| 계략 | 화공 실행 / 혼란 / 고무(아군 사기 회복) |
| 이동 | 추격 / 추격 금지 / 퇴각 / 지정 지점으로 이동 |
| 일기토 | 지정 장수에게 일기토 신청 |

### 8-4. 예시
```
[전군] 바람이 동남풍으로 바뀌면 → 화공 실행 (담당: 화공 장수)
[전군] 적 사기가 30 이하가 되면 → 전군 맹공으로 전환 + 추격
[전군] 아군 선봉 병력이 40% 이하가 되면 → 예비대 투입
[조운 부대] 적 총대장 위치가 노출되면 → 목표를 적 총대장으로 변경
[장비 부대] 적이 다리에 진입하면 → 사수, 추격 금지
```

### 8-5. 실행 신뢰도
조건 명령은 **반드시 지켜지는 게 아니다.** 장수와 상황에 따라 달라진다.
- **조건 감지**: 조건이 일어난 걸 알아채는 것. 지휘 범위 안이면 확실, 밖이면 지력 판정
- **명령 준수**: 성격에 따라 어길 수 있다
  - 오만: "추격 금지"를 무시하고 추격할 수 있다 (적이 일부러 퇴각하는 척하는 유인에 걸림)
  - 호걸: 일기토 신청을 받으면 "거절" 명령을 무시할 수 있다
  - 신중: "맹공 전환"을 늦게 실행한다
- 어긴 경우 결과 보고서에 **"○○ 장군이 명령을 어기고 추격했습니다"**라고 명확히 기록한다. 플레이어가 장수의 성격을 배우게 된다.

### 8-6. 2단계 작전 (전군 방침 전환)
- 전군 조건 명령 중 1개를 "방침 전환"에 쓸 수 있다.
- 예: "견고 수비로 시작 → 적 사기 40 이하가 되면 → 유인 역습으로 전환"
- 지력 80+ 군사가 있어야 사용 가능. 전환 직후 1~2턴은 진형이 흔들려 약해진다.

## 9. 정찰과 적 방침 예측

자동 전투에서는 **적이 무엇을 할지 예측하는 것**이 곧 실력이다.

### 9-1. 정찰 수준
| 수준 | 얻는 방법 | 공개 정보 |
|---|---|---|
| 0 | 없음 | 적 병력 대략 (±30%) |
| 1 | 출진 전 정찰 명령 | 정확한 병력, 병종 구성 |
| 2 | 정찰 + 첩자 | 장수 명단, 대략적인 배치 |
| 3 | 정찰 + 첩자 + 지력 높은 군사 | 적 **방침 예측** 제공 |

### 9-2. 군사의 예측
- 군사가 적 방침을 확률로 예측한다: **"적은 매복 요격 가능성 60%, 견고 수비 30%"**
- 정확도 = 우리 군사 지력 - 적 지휘관 지력 + 정찰 수준 보정
- 예측이 틀릴 수 있다. 결과 보고서에서 실제 적 방침이 공개되므로, 플레이어는 어느 군사의 말을 믿을지 배우게 된다.

### 9-3. 기만
- 지력 80+ 지휘관은 **위장 방침**을 설정할 수 있다. 적 군사의 예측이 위장 방침 쪽으로 기운다.
- 위장이 들킬 확률 = 적 군사 지력 판정
- AI도 똑같이 쓴다. 그래서 상대가 제갈량이나 사마의면 예측을 믿기 어려워진다.

## 10. 자동 전투 엔진

### 10-1. 기본 사양
- 전장은 기존 헥스 맵을 그대로 쓴다. 지형, 날씨, 낮밤, 지휘 범위, 방향, ZOC, 사기, 매복 판정 등 설계노트 11장의 규칙은 **엔진 내부 규칙**으로 유지된다.
- 최대 30턴, 1턴 = 반나절 (설계노트 35-1 그대로)
- 모든 난수는 시드 난수 (설계노트 30-1). 같은 작전과 시드면 같은 결과 → 리플레이와 버그 재현 가능

### 10-2. 매 턴 각 부대의 처리 순서
```
1. 조건 명령 체크 (감지 판정 → 준수 판정)
2. 현재 방침과 역할에 따라 목표 위치 결정
3. 태도에 따라 이동 또는 교전 결정
4. 성격 이탈 판정 (오만한 추격 등)
5. 계략 사용 판정 (계략 방침 + 성공률)
6. 일기토 발생 판정 (일기토 방침 + 수락 판정)
7. 전투 피해 계산 (설계노트 23-1)
8. 사기 변화와 전파, 패주 판정
```

### 10-3. 실행도 (작전이 얼마나 잘 수행되는가)
```
실행도 = 총대장 통솔 × 0.5 + 군사 지력 × 0.3 + 부대 평균 훈련도 × 0.2
```
- 방침마다 **요구 실행도**가 있다 (정면 돌파 0, 학익 포위 55, 성동격서 70, 허장성세 85 등)
- 실행도가 요구치보다 낮으면 상성 보정이 줄어들고, 크게 모자라면 **부대들이 따로 놀아** 오히려 불리해진다
- 그래서 지력 낮은 장수끼리는 단순한 작전이 낫고, 명장과 명군사가 있어야 복잡한 작전이 빛난다

### 10-4. 일기토 (자동화)
- 설계노트 12장의 선택형 일기토는 **자동 진행**으로 바뀐다
- 매 합의 행동(공격, 강공, 방어, 견제, 필살, 도발)은 장수의 **성격과 능력치**로 엔진이 고른다
- 플레이어가 영향을 주는 방법은 사전 설정뿐: 일기토 방침(7-5), 일기토 상대 지정(조건 명령)
- 특수 매치업 연출(설계노트 12-4)과 난입은 그대로 유지. 관전 화면에서 **하이라이트로 자동 재생**

### 10-5. 설전
- 설계노트 13장의 설전은 **작전 회의 전 단계**로 옮긴다
- 전투 직전 양군 대치 장면에서 진행 (자동 또는 1회 선택). 결과가 양측의 시작 사기에 반영된다

## 11. 관전 화면

### 11-1. 진행 속도
| 모드 | 용도 |
|---|---|
| 1배속 | 큰 결전을 감상 |
| 2배속 / 4배속 | 일반 전투 |
| 하이라이트만 | 중요 장면만 보여 주고 나머지는 빨리 감기 |
| 결과만 | 바로 보고서로 |

### 11-2. 화면 구성
- **중앙**: 헥스 전장 위에서 부대가 움직이는 모습
- **상단**: 양군 병력과 사기 막대, 경과 턴, 날씨·바람·낮밤
- **측면**: 전황 해설 로그
  - 「조운이 적 좌익을 돌파했다!」
  - 「동남풍이 분다. 화공의 조건이 갖춰졌다.」
  - 「장비가 명령을 어기고 추격에 나섰다!」
- **하단**: 조건 명령 발동 표시 (어떤 명령이 언제 발동했는지 아이콘으로)

### 11-3. 하이라이트 자동 연출
아래 순간에는 화면이 자동으로 줌인되고 짧은 연출이 나온다.
- 일기토
- 매복 발동
- 화공·수공
- 장수 격파 또는 포로
- 조건 명령 발동
- 총대장 퇴각, 전군 패주
- 성문 돌파

### 11-4. 개입 금지 원칙의 UI 표현
- 관전 중에는 명령 버튼이 **아예 없다**. 있다가 비활성화되면 답답하다
- 할 수 있는 것: 속도 조절, 카메라 이동, 부대 정보 보기, 하이라이트 다시 보기

## 12. 전투 결과 보고서

자동 전투에서 가장 중요한 화면이다. **다음 작전을 더 잘 짜게 만드는 화면**이어야 한다.

| 항목 | 내용 |
|---|---|
| 승패와 승리 조건 | 총대장 격파, 적 전멸, 턴 제한 등 |
| 피해 | 양군 병력 손실, 부상 장수, 포로 |
| **적 방침 공개** | "적은 ○○ 방침이었다" + 상성 결과 (▲▲ 우리 유리했음) |
| 군사 예측 적중 여부 | "군사의 예측: 매복 요격 60% → 적중" |
| 조건 명령 기록 | 각 명령이 언제 발동했고 지켜졌는지 |
| **명령 위반 기록** | 누가 언제 어떤 명령을 어겼는지 |
| 장수 평점 | 장수별 10점 만점 평점, MVP |
| 주요 장면 | 하이라이트 목록 (클릭하면 다시 보기) |
| **군사 총평** | 패인·승인 분석과 다음 제안. 「적의 매복에 선봉이 걸렸습니다. 다음에는 정찰을 먼저 하시지요.」 |
| 전투 지도 요약 | 부대 이동 경로와 주요 교전 지점 |

- 이 보고서가 연대기(설계노트 17-2)와 장수 열전에 자동 반영된다.

## 14. 데이터 구조 예시

방침, 역할, 조건 명령을 **모두 데이터(JSON)로** 두면 코드 수정 없이 방침을 추가하고 밸런스를 조정할 수 있다.

### 14-1. 방침

## 15. 밸런스 기준과 테스트 방법

### 15-1. 목표
| 항목 | 기준 |
|---|---|
| 지배 방침 없음 | 동일 전력에서 어떤 방침도 모든 상대 방침과 붙었을 때 평균 승률이 **45~55%** 범위 |
| 상성의 크기 | 상성 최대치(▲▲)로 뒤집을 수 있는 전력 차는 약 30% |
| 능력의 가치 | 같은 방침이라도 실행도 30 차이면 승률 15%p 이상 차이 |
| 전투 시간 | 1배속 관전 기준 일반 전투 3~5분, 결전 10분 내외 |
| 조건 명령의 가치 | 조건 명령을 잘 쓴 쪽이 안 쓴 쪽보다 승률 10%p 이상 높음 |

### 15-2. 테스트 방법
- **방침 매트릭스 자동 시험**: 모든 공격 방침 × 모든 방어 방침 조합을 동일 전력으로 각 100번씩 헤드리스로 돌려 승률표를 뽑는다
- 표에서 어느 방침이든 승률 60%가 넘거나 40% 미만이면 수치를 조정한다
- 그다음 능력치 차이, 병력 차이, 지형별로 같은 시험을 반복한다

## 16. 단계별 구현 순서

게임이 거의 완성된 상태이므로 **한 번에 다 바꾸지 말고** 단계별로 간다.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **1단계 (최소 버전)** | 작전 회의 1단(전군 방침), 공격 6종(A1~A6), 방어 6종(D1~D6), 역할 5개(선봉·중군·좌익·우익·예비대), 태도 3단계(공격·균형·신중), 퇴각 기준, 6×6 상성, 자동 전투, 간단한 결과 보고서(승패·피해·적 방침 공개) | 작전만 정하고 끝까지 자동으로 전투가 끝난다. 방침 매트릭스 시험에서 지배 방침이 없다 |
| **2단계** | 정찰과 군사 예측, 전군 조건 명령, 계략·일기토 방침, 자동 일기토, 관전 속도 조절과 해설 로그, 결과 보고서 확장 | 조건 명령으로 화공·예비대 투입이 자동으로 일어난다 |
| **3단계** | 나머지 방침(A7~A14, D7~D14), 진형, 태도 5단계, 부대별 조건 명령, 2단계 작전, 기만, 실행도에 따른 명령 위반, 하이라이트 연출, 작전 프리셋, 리플레이 | 덕후가 작전 회의에서 10분씩 고민하게 된다 |
