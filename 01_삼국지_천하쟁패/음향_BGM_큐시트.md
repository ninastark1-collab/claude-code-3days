### 작곡 원칙

- **전곡 창작.** 기존 상용 게임·영화 음악의 선율, 화성 진행, 편곡을 쓰지 않았다 (개발자 전달서 A1 독창성 점검 대상 아님).
- 선율은 5음 음계: 밝은 곳은 궁조(1 2 3 5 6), 긴장·비장은 우조(1 ♭3 4 5 ♭7).
- 세력·전투가 커질수록 타악이 늘어난다: 평시(방자) → 전운(대고) → 출진(대고+당고) → 공성(대고 매 박+대라) → 일기토(전부+소라).
- 체감 음량은 전곡 RMS -19dBFS로 맞췄다. 곡이 바뀌어도 소리 크기가 튀지 않는다.

## 2. 개발 연결 방법 (필수 2곳 + 권장 2곳)

### ① 필수: 자동 선곡 켜기 — `src/main.tsx`

```ts
import { startBgmDirector } from './audio/director';
// ...
installPlatform();
applySettings();
startBgmDirector();
```

이것만으로 타이틀·시나리오·지도·도시·외교·작전 회의·야전·공성·승패 결과·엔딩 곡과, 역사 이벤트·사망·새 계절·적 침공·승리·패배 효과 음악이 모두 나온다.

### ② 필수: 일기토 알리기 — `src/ui/screens/Battle.tsx` 의 `Spectate`

일기토 장면은 화면 내부 상태(`duel3d`, `duelIdx`)라 감독이 볼 수 없다. `Spectate` 안에 아래 한 덩어리를 넣는다.

```ts
import { setBgmDuel } from '../../audio/director';
// Spectate 안, duel3d·duelIdx 선언 아래
useEffect(() => {
  setBgmDuel(duel3d !== null || duelIdx !== null);
  return () => setBgmDuel(false);
}, [duel3d, duelIdx]);
```

### ③ 권장: 겹치는 효과음 정리

BGM 효과 음악이 같은 순간을 맡으므로 아래 기존 효과음은 빼는 걸 권한다 (둘 다 울리면 지저분하다).

| 위치 | 지금 | 권장 |
|---|---|---|
| `Battle.tsx` 관전 루프의 `if (b.result) sfx(... 'win' : 'lose')` | 승패 효과음 | 삭제 (`st_victory`/`st_defeat`가 대신함) |
| `Strategy.tsx` `EndingScreen`의 `sfx(e.type === 'victory' ? 'win' : 'lose')` | 엔딩 효과음 | 삭제 (엔딩 곡이 바로 나옴) |
| `store.ts` 방어전 대기 `sfx('alarm')` | 경보음 | 둘 중 하나만. 짧은 알림이 필요하면 유지하고 `director.ts`의 `st_alarm` 줄 삭제 |

`click`·`ok`·`ng`·`hit`·`battle`은 그대로 둔다.

### ④ 권장: 설정 화면 (S17 소리 탭)

지금 소리 탭에는 "효과음" 하나뿐이다. 아래 두 줄을 추가하면 된다 (UI 모양은 디자이너 몫, 동작 함수만 준비).

```ts
import { getBgmVolume, isBgmMuted, setBgmMuted, setBgmVolume } from '../../audio/bgm';
// 배경음 켜기/끄기  → setBgmMuted(!on)
// 배경음 크기 0~1   → setBgmVolume(v)   (기본 0.55, 기기마다 저장)
```

## 3. 동작 방식 (알아 두면 좋은 것)

- **음원 파일이 없다.** 곡을 처음 틀 때 작업자(Web Worker)가 악보를 1~2초 동안 합성한다. 합성 중에는 이전 곡이 계속 나오고, 다 되면 1.6초 교차 페이드.
- 다음에 나올 법한 곡은 미리 합성한다 (지도 → 작전 회의·도시, 작전 회의 → 야전·공성, 전투 → 일기토·승리).
- 합성해 둔 곡은 6개까지 기억한다 (곡당 2~8MB, 24kHz 스테레오).
- 앱이 뒤로 가거나 창이 가려지면(`visibilitychange`) 오디오를 멈추고, 돌아오면 이어서 튼다 → 폰 배터리·QA 폰 기준 대응.
- 브라우저 자동재생 제한이 있는 환경에서는 첫 터치·키 입력에 깨어난다. Electron은 기본으로 바로 나온다.
- 같은 화면 안에서 다시 그려져도 같은 곡이면 처음부터 다시 틀지 않는다.
- 야전/공성 구분: 지금 전장은 모두 성을 끼고 있어서, **성이 있느냐가 아니라 공격군이 성벽·성문 2칸 안에 들어왔느냐(또는 성벽에 불이 붙었느냐)**로 가른다. 한 번 공성 곡으로 바뀌면 그 전투가 끝날 때까지 유지한다. 수비군이 나와서 들판에서 끝난 전투는 끝까지 `출진`이다.
- 전운(`map_war`): 방어전 대기 중이거나, 마지막 전투 후 2개월 동안. 이 기준은 `director.ts`의 `atWar` 한 줄에서 바꿀 수 있다.

## 4. 확인 방법

```bash
npx vitest run tests/bgm.test.ts
```

```bash
npx tsx scripts/render-bgm.ts
```

위 명령은 `design/bgm/*.wav` 21개를 다시 만든다 (미리듣기용, 게임에서 쓰지 않음, 약 58MB. 설치파일에 들어가지 않는다).

브라우저 미리듣기:

```bash
npx vite --port 5179
```

그다음 `http://localhost:5179/design/bgm-preview.html` — 게임과 같은 재생기로 곡별 재생, "→"가 붙은 효과 음악은 다음 곡으로 넘어가는 것까지 들을 수 있다.

### 확인한 것 (2026-11-13)

- 21곡 모두 악보 박 수 검사 통과, 깨짐 없음(봉우리 ≤ 0.95), NaN 없음, 루프 이음매 튐 없음
- 브라우저 작업자 합성 시간: 루프곡 0.7~1.8초
- 실제 게임(개발 서버)에 감독을 붙여서 확인: 타이틀 → 군주 선택 → 지도 → 도시 → 외교 → 지도 → 작전 회의 → 야전(공성) → 승리 효과 음악 → 개선 순으로 곡이 바뀜. 수비군이 나와 들판에서 끝난 전투는 `출진` 유지 → 패전 효과 음악 → 패주
- **확인 못 한 것:** 일기토 곡 전환은 ②를 연결해야 동작한다. 폰 실기 재생, 설치판(Electron file://)에서의 작업자 동작은 아직 확인하지 않았다 (인라인 작업자라 file://에서도 돌아가는 방식이고, 실패하면 메인 스레드에서 합성하도록 대비해 둠)
