# 개발자 전달서: 설계노트 적용 요청

> 대상: 거의 완성된 빌드를 가진 개발자
> 참고 문서: [게임마스터_설계노트.md](게임마스터_설계노트.md) (43장), [게이머_위시리스트.md](게이머_위시리스트.md)
> 이 문서만 읽으면 무엇을, 어떤 순서로, 어디까지 하면 되는지 알 수 있게 썼다.

---

## 0. 먼저 읽어 줘: 요청의 전제

1. **43장을 전부 넣어 달라는 게 아니다.** 게임이 거의 완성된 상태라 큰 구조를 갈아엎는 건 현실적이지 않다.
2. 아래 항목을 **A(출시 전 필수) / B(출시 전 권장) / C(업데이트 이후)**로 나눴다. A만 해도 충분히 의미 있다.
3. **고치기 전에 먼저 현재 상태를 알려 줘.** 각 항목이 "이미 있음 / 비슷하게 있음 / 없음" 중 어디인지 표시해 주면, 내가 다시 우선순위를 조정할게.
4. 내 의견과 네 설계가 다르면 **네 판단이 우선**이다. 대신 "왜 안 넣는지" 한 줄만 적어 줘.

---

## 1. 작업 방식

```
1단계: 아래 표의 "현재 상태" 칸을 채워서 돌려준다  (코드 수정 없음)
2단계: 함께 A 항목 범위를 확정한다
3단계: A 항목을 하나씩 반영한다  (항목 하나 = 커밋 하나 추천)
4단계: 반영한 항목마다 "완료 기준"을 직접 확인하고 표시한다
5단계: 테스트 빌드를 넘겨주면 내가 31장 체크리스트로 검증한다
6단계: B, C는 A가 끝난 뒤 같은 방식으로
```

## 1-1. ★ 전투 개편 v2 (최우선, 별도 문서)

자동 전투 1단계 구현 고마워. 직접 플레이하고 측정해 보니 큰 문제가 있어서 설계를 다시 썼다. 상세 내용은 [전투개편_v2_전례기반_설계서.md](전투개편_v2_전례기반_설계서.md)에 있다. v1 설계서는 대체되었다.

**측정 결과 (v0.2.1, 자동 전투 400회)**: 무력 85+ 장수가 참전한 전투 299회 중 **일기토 0회**, 평균 전투 1배속 약 47초, 화면 로그는 마지막 3줄만 보임. 원인과 코드 위치는 v2 설계서 1장에 있다. 다시 재려면 `npx tsx qa/scripts/probe-duel.mts`.

작업 순서 (v2 설계서 11장):
| 순위 | 내용 | 등급 |
|---|---|---|
| **1** | 일기토가 자동 전투에서 안 일어나는 버그 + 일기토 전용 장면 복원 + 큰 사건 배너·자동 감속 + 로그 6줄 | **A (출시 전 필수)** |
| 2 | 대치 국면 추가 (계책 16종 중 우선 척후·보급 기습·화공 준비·견수불출·의병) | A |
| 3 | 결전 방침을 시작 위치가 아니라 행동 규칙으로 교체, 숨은 `power` 배율 제거 | B |
| 4 | 추격 국면, 역사 전투 시나리오 | B → C |

1순위만 먼저 해 주면 내가 바로 다시 측정할게.

### 역사 전투 시나리오 (4순위 상세)
[전투시나리오/](전투시나리오/역사전투_13선_상세.md) 폴더에 15개 전장을 데이터 초안까지 준비해 뒀다.
- `battle-scenarios.draft.json`: 전장 지형, 배치 좌표, 이벤트, 분기, 일기토 매치업. 장수 id는 네 데이터 기준으로 검증했다 (`node 전투시나리오/validate-scenarios.cjs`, 오류 0)
- 먼저 필요한 엔진 작업: **전장을 데이터로 받기**, 성 위치 하드코딩 제거(`auto.ts:14`, `ai.ts:14`, `battle.ts:74-88`), 야전 맵, `navy` 병종 (상세 2장)
- 순서 추천: **번성·형주(s219 첫 달) → 관도 3부작(s200) → 적벽·장판(s208)**. 시나리오를 시작하자마자 만나는 전투라 첫인상을 정한다
- 시나리오 데이터 담당에게 넘길 것: 이전 사망년(209) ↔ 215년 합비 참전 충돌, 촉 장남 동명이인 누락 (상세 8장)

## 4. C등급: 업데이트 이후 (지금은 하지 마)

출시 후 업데이트나 확장으로 미룰 것들. **지금 손대면 출시가 늦어진다.**

- 숨은 파라미터, 관계망 확장 (3장)
- 군단제 (4-4), 첩보 확장 (7장), 외교 확장 (8장)
- AI 성격 프로파일 (9장)
- 전투 개편 v2의 나머지 대치 계책, 역사 전투 시나리오 2번째 이후 (v2 설계서 4장, 8장)
- 화공·수공 시뮬레이션, 공성 병기 (11장, 자동 전투 엔진 안에서)
- 설전 (13장, 전투 직전 단계로)
- 연대기, 엔딩 분기 (17-2, 27장)
- 시설·기술 트리 (21장), 정예 부대 (22장)
- 장수 플레이, 핫시트 (26장)

※ 이 중에 **이미 비슷한 게 들어가 있다면** 알려 줘. 그건 B등급으로 올려서 다듬는 방향으로 보자.

## 5. 결과를 돌려줄 때 형식

```
- 한 일: (한두 줄)
- 확인 방법: (내가 어떻게 테스트하면 되는지)
- 보류 이유: (보류인 경우만)
```

## 6. 하지 말아 줘

- 43장 전부를 한 번에 넣으려고 하지 마. 버그만 늘어난다.
- A 항목을 하면서 C 항목을 슬쩍 같이 넣지 마. 한 번에 한 항목.
- 설계노트의 수식(23장)은 출발점일 뿐이다. 지금 게임의 수식이 잘 돌아가면 바꾸지 마.
- 내 의견 때문에 네가 좋다고 생각한 설계를 버리지 마. 반대 의견은 언제든 환영이다.
