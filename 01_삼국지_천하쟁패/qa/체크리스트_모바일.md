# 체크리스트: 모바일 (최우선)

> **이 게임의 최종 판정 기준은 폰이다.** PC·웹에서 통과해도 폰에서 실패하면 실패다.
> 자동 = `probe-mobile.cjs`(Electron 에뮬레이션: 터치 이벤트만 사용, 저사양 CPU 배율), 실기기 = 플레이테스트 S9.
> 에뮬레이션 통과는 "필요조건"일 뿐이다. 출시 판정은 **실기기 결과**로 한다.

## 기기 행렬 (가로 화면 CSS 크기)

| ID | 기기 | 크기 | 왜 | 자동 | 실기기 |
|---|---|---|---|---|---|
| iphone14 | iPhone 12~15 | 844×390 | 디자인 기준 해상도 | ✅ | 필수 |
| iphoneSE | iPhone SE | 667×375 | 가장 작은 화면 → 배율 0.79, 버튼·글자 축소 | ✅ | 권장 |
| galaxyA | 보급형 갤럭시 A | 740×360 | **CPU 4배 느림** — 판매량 많은 저사양 | ✅ | **필수** |
| pixel7 | Pixel·갤럭시 S | 915×412 | 세로가 긴 비율 | ✅ | 권장 |
| promax | iPhone Pro Max | 932×430 | 다이내믹 아일랜드, 큰 안전 영역 | ✅ | 권장 |
| tablet | iPad·갤럭시 탭 | 1024×768 | 비율이 크게 다름 | ✅ | 선택 |

## 판정 항목

| ID | 항목 | 기준 | 자동 | 등급(실패 시) |
|---|---|---|---|---|
| M0 | 터치만으로 진행 | 타이틀 → 새 게임 → 지도 → 명령 → 다음 달 → 출진 → 전투 → 저장이 **손가락 탭만으로** 됨 | ✅ | S1 |
| M1 | 터치 영역 | 실제 화면에서 44px 이상 (36px 미만은 실패). 작은 폰에서는 배율 때문에 줄어든다는 점 주의 | ✅ | S2 |
| M2 | 겹침·간격 | 터치 영역끼리 겹치지 않고, 작은 버튼 사이 간격 4px 이상 | ✅ | S2 |
| M3 | 화면 밖 | 조작 요소가 화면 밖으로 나가지 않음. 꼭 눌러야 하는 버튼이 화면 밖이면 S1 | ✅ | S1/S2 |
| M4 | 실제 글자 크기 | 배율 반영 후 11px 이상 (9px 미만은 실패) | ✅ | S3 |
| M5 | 잘림 | 글자가 줄임표 없이 잘리지 않음 | ✅ | S3 |
| M6 | 노치·안전 영역 | `viewport-fit=cover`, `env(safe-area-inset-*)` 반영, 조작 요소가 노치·둥근 모서리에 안 가려짐 | ✅ | S2 |
| M6 | 제스처 충돌 | 두 번 탭 확대·핀치 페이지 확대·당겨서 새로고침·글자 선택 돋보기가 안 생김 | ✅ | S2 |
| M7 | 마우스 전용 | `:hover`·`title` 툴팁에만 있는 정보 없음. 모두 길게 누르기로도 열림 | ✅ | S2 |
| M8 | 시작 시간 | 앱 아이콘 → 타이틀 3초, 시작 → 지도 3초 (보급형 기준) | ✅ | S3 |
| M9 | 프레임 | 지도 끌기·전투 30fps 이상 (보급형). 가만히 있을 때는 그리기를 멈춤(배터리) | ✅ | S2 |
| M10 | 제스처 | 한 손가락 이동, 두 손가락 확대, 두 번 탭 확대, 길게 누르기(0.35초) 정보 | 반자동(스크린샷) | S2 |
| M11 | 턴 처리 | 다음 달 → 조작 가능까지 5초 이내 (보급형), 그동안 진행 표시 | ✅ | S3 |
| M12 | 백그라운드 | 홈 버튼·전화·알림으로 앱이 뒤로 가면 **즉시 자동 저장**하고 전투는 **일시정지** | ✅ | S2 |
| M13 | 강제 종료 | 앱을 날려도(최근 앱에서 밀기) 다시 켜면 마지막 자동 저장부터 이어짐 | 반자동 | S1 |

| M14 | 화면 방향 | 가로 고정 또는 세로일 때 "가로로 돌려 주세요" 안내 | ✅ | S2 |
| M15 | 메모리 | 1시간 플레이 후에도 웹뷰가 강제 종료되지 않음 (JS 힙 300MB 미만) | ✅ | S1 |
