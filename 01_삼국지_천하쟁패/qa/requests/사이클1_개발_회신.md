## 먼저 — 폰 빌드 방식 (DEV-01, 방침 질문 1)
- **방식: Capacitor 8 (기존 Vite 빌드 `dist/`를 그대로 감쌈) + 같은 빌드를 PWA로도 배포.**
- 안드로이드: 저장소에 `android/` 프로젝트가 들어 있다. `npm run android:apk` → `release/samgukji-<버전>-debug.apk`, `npm run android:aab` → 스토어용 AAB(서명 설정 필요). 빌드 PC에 JDK 21과 Android SDK(Android Studio)가 있어야 한다. **지금 개발 PC에는 둘 다 없어서 APK 실물은 아직 못 만들었다.** 도구가 설치되는 대로 첫 APK를 올린다.
- iOS: macOS + Xcode에서 `npx cap add ios` 한 번 → `npm run ios:sync` → Xcode Archive. 맥 장비가 생기면 진행한다.
- **지금 바로 폰 테스트 가능: PWA** — https://samgukji-cheonha-delta.vercel.app/install
  - 안드로이드 Chrome·삼성 인터넷: "앱 설치하기" 버튼 한 번으로 홈 화면에 설치된다(전체 화면·가로 고정).
  - 아이폰 Safari: 공유 → 홈 화면에 추가 안내가 나온다.
  - 카카오톡 등 메신저 안 브라우저로 열면 Chrome/Safari로 넘기는 버튼이 나온다.
  - 한 번 열면 오프라인에서도 실행된다(서비스 워커). 저장은 기기 브라우저 저장소(영구 저장 요청)에 남는다.
  - 폰 실기기 테스트는 이 주소로 해 주면 된다. 네이티브 앱(APK)과 화면·엔진은 같은 `dist`다.

## 방침 질문 답변
1. **폰 빌드:** Capacitor 8 + PWA. 위 "먼저" 참고. PWA는 오늘부터 테스트할 수 있고, APK는 빌드 도구가 설치되는 대로 진행한다.
2. **강 도하:** 의도했다. 강 칸은 여울로 다룬다. 이동 3.5(수군 1.5), 그 칸에서 받는 피해 +20%, 강에서 공격하면 ×0.7(수군 제외). 3D에서도 여울로 그린다. "강은 수군만"은 수상전(적벽) 단계에서 다룬다.
3. **도시 0 = 즉시 멸망:** 의도했다. 방랑·의탁(설계 39장)은 이번 출시 범위 밖(C등급)이다.
4. **30일 = 수비 승리:** 의도했다. 공성 "포위 이월"은 아직 없다. 출시 후 검토한다.
5. **군주 포로 = 즉시 계승:** 의도했다. 몸값·구출은 아직 없다.
6. **전투 결정론:** 의도했다. 시드 기반이라 세이브 스컴으로 결과가 바뀌지 않는다.
7. **난이도:** 지금은 AI 공격 문턱과 AI 수입만 바뀌고, 게임 중 표시가 없다. 표시 위치와 체감 차이(예: 개막 정비 기간 길이, AI 등용 문턱)는 디자인과 정해서 사이클 2에 반영한다.
8. **전투개편 단계:** v2 **1단계(작전 회의 → 자동 전투 관전)**와 3D 연출(전장·일기토 무대·공성 분담)까지 들어갔다. 2·3단계는 아직이니 1단계까지만 검사해 줘.
