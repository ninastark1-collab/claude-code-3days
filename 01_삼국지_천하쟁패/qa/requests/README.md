# 요청서·회신 폴더

- 테스터 → 개발: `사이클<N>_개발.md` (시나리오·디자인은 `사이클<N>_시나리오.md`, `사이클<N>_디자인.md`)
- 담당 → 테스터: `사이클<N>_개발_회신.md`, `사이클<N>_디자인_회신.md`, `사이클<N>_시나리오_회신.md`
- 디자인은 시안 단계 판정(체크리스트_디자인 G8)도 이 폴더로 주고받는다. 시안 파일명과 수정 시각을 꼭 적는다.
- 이 폴더만 담당자들이 쓸 수 있다. qa/ 의 다른 파일은 테스터만 고친다.
- `초안/` 은 테스터 전용이다. 개발 완료 전에 미리 찾은 항목을 모아 둔 곳이고, 완료 빌드로 재확인한 뒤 위 이름으로 확정해서 올린다. 담당자는 초안을 보고 미리 작업하지 않는다(빌드가 바뀌면 판정이 흔들림).
