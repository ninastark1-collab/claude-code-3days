# 플레이테스트 세션 대본

> 각 세션마다 시작 전에 기록: 빌드 시각/버전, 시나리오, 세력, 난이도, 이벤트 on/off, **시드**(가능하면), 창 크기(1280×800 / 844×390).
> 문제를 보면 즉시: 스크린샷 → 수동 저장(남는 슬롯) → 로그(기록 창) 복사 → 버그 메모. 그 다음 계속 진행.
> 시간은 실제 타이머로 잰다 (42장 템포 목표 비교).

| 3 | 194 / 아무 세력 / 보통 → 시작 | 로딩 표시 후 맵 진입 (무반응 1초 이상이면 기록) |

| 9 | 게임 방법 / 효과음 토글 / 종료 | 동작 |

## S1. 첫 1시간 (20-2, 42장 템포)

목표: 처음 하는 사람처럼. **튜토리얼 없이** 진행.
- 기록할 숫자: 첫 출진까지 걸린 시간(목표 15분 이내), 도시 하나 내정 명령에 필요한 클릭 수(목표 3클릭), 초반 1개월 턴 평균 시간(목표 1~2분), AI 턴 대기(목표 5초 이내), 저장·불러오기 시간(목표 3초 이내), 자동 전투 시간(목표 10초).
- 관찰: 무엇을 해야 할지 헤맨 순간, 숫자 의미를 몰랐던 곳, 같은 클릭을 반복한 곳.
- 판단: 첫 전투에서 "내 판단으로 이겼다"는 느낌이 드는가. 아니면 왜 아닌가.

각 시나리오에서 **역사적 주인공 세력**과 **약소 세력** 하나씩.

| 시나리오 | 주인공 | 약소 | 보는 것 |
|---|---|---|---|
| s184 | 유비군 | 한수군 | 도원결의 발동, 황건 세력의 흐름, 유비 근거지 없이 재기 가능성 |
| s190 | 조조군 | 공주군/왕광군 | 반동탁 연합의 분위기, 동탁 세력 강도, 화웅 등 연의 장면 |
| s194 | 유비군 | 공손도군/장연군 | 첫 달 판세 붕괴 여부, 손책 독립 이벤트(195~) |
| s200 | 조조군 | 공손도군 | 관도 구도(조조 vs 원소), 천리행, 손책 사망 |
| s208 | 유비군 | 공손강군 | 장판·적벽·동남풍, 유표 사망 흐름 |

## S4. 장기 플레이 (10시간 체크, 압축)

- 한 판을 끝까지(통일 또는 멸망). 위임·자동 전투 적극 사용해 속도를 낸다.
- 1년마다 기록: 내 도시 수, 금·쌀, 무장 수, 1개월 턴 소요 시간, 세이브 용량.
- 관찰: 반복 노동 구간(같은 명령 매달 반복), AI의 빈집 털기·병력 집중, 애착이 생긴 무명 장수, 같은 일기토 반복 시 질림, 후반 턴이 초반보다 3배 넘게 길어지는가(42장).
- 엔딩 화면까지 확인 (S29).

## S5. 전투 집중 (1시간, 작전 회의 → 자동 전투)

> 전투는 개입 없는 자동 전투다(설계서 1장). "직접 지휘가 없다"는 이유로 FAIL을 내지 않는다. 대신 **작전을 짜는 재미와 결과의 납득**을 본다.

| # | 상황 | 기대 |
|---|---|---|
| 1 | 처음 하는 사람처럼 첫 전투: 아무 설명 없이 작전 회의 화면 | 30초 안에 "무엇을 고르면 되는지" 안다. 방침 1개만 고르고 시작 가능 |
| 2 | 같은 적에게 방침 6종을 하나씩 (같은 세이브에서) | 결과가 방침마다 다르고, 보고서의 상성 설명이 실제 결과와 맞음 |
| 3 | 군사 진언/위임만 써서 5전 | 위임이 "아무거나"보다 나음. 진언 문장이 매번 같지 않음 |
| 4 | 통솔·지력 낮은 장수로 어려운 방침 | 실행도 경고가 확정 전에 보임. 보고서에 "부대가 따로 놀았다" 류 원인 |
| 5 | 관전 1배 → 4배 → 결과만 | 속도만 바뀌고 결과 동일. 폰에서 끊김 없음 |
| 6 | 관전 중 홈 버튼 10초 | 멈춰 있다가 이어짐 |
| 7 | 패배 직후 보고서만 읽고 재도전 | 총평대로 바꿨을 때 실제로 나아짐 (총평이 거짓말이면 S2) |
| 8 | 방어전: 적 침공 → 수비 작전 / 위임 | 잃은 도시·이유가 결과 팝업에 반드시 뜸 |
| 9 | 군량 부족 상태로 출진 | 작전 회의에서 경고, 전투에서 사기 폭락·퇴각이 보고서에 기록 |
| 10 | 같은 전투 10회(다른 세이브 시점) | 일기토·로그 문장 반복으로 질리지 않는가, 조사 오류("장보이(가)") 없음 |
| 11 | **회귀 케이스**: s194 유비, 1월, 유비 단독(9,000) → 수춘(원술 15,000) 출진 → 위임 | 병력 열세 공격이 성을 함락하면 기록 (사전관찰 #1). 5회 반복 승률 |
| 12 | 2단계 이후 기능(정찰·조건 명령·하이라이트)이 화면에 있으면 | 각각 1회 이상 발동하고 보고서에 기록 |

## S6. 예외 상황 강제 재현 (39장 12종)

자동 재현(probe-edge)과 별도로, 화면에서 직접 한 번씩 본다. 재현이 어려우면 probe-edge 결과 세이브를 불러와서 본다.

| # | 상황 | 재현 방법 | 기대 처리 |
|---|---|---|---|
| 1 | 군주 포로 | 군주 단독 소병력 출진 → 패배 | 후계 대리·몸값·구출, 메시지 순서(원인 → 결과) |
| 2 | 군주·후계자 같은 달 사망 | probe-edge 세이브 | 추대 즉시 |
| 3 | 원정 중 본거지 전부 함락 | 전 병력 출진 후 턴 종료 | 원정군 점령 도시가 새 본거지 / 방랑군 |
| 4 | 도시 0 + 군주 생존 | 위 연장 | 방랑·의탁 |
| 5 | 동맹과 공동 점령 | 동맹 후 같은 도시 공격 | 소유 규칙 |
| 6 | 같은 달 같은 빈 도시 | probe-edge | 먼저 도착 입성, 나중은 공성 |
| 7 | 원정 중 목적지 주인 변경 | 이동 시간 있는 출진(있다면) | 36-3 |
| 8 | 총대장 일기토 사망 | 일기토 반복 | 승계 → 사기 -30 → 패주 |
| 9 | 퇴각 지점 봉쇄 | 포위당하게 배치 | 결사 또는 포로 |
| 10 | 화공 아군 번짐 | 아군 인접 화계 | 번지고 경고 표시 |
| 11 | 이벤트 대상이 도중 사망 | probe-edge | 이벤트 중단 |
| 12 | 생년 불명 장수 | 데이터 확인 | 추정 표시 |

## S9. 실기기 (출시 판정의 기준, 매 사이클 필수)

> 에뮬레이션(probe-mobile)이 통과해도 이 세션을 건너뛰지 않는다. 최소 **보급형 안드로이드 1대 + 아이폰 1대**.

준비
- 앱 포장본(APK/TestFlight)이 있으면 그것으로. 없으면 같은 Wi-Fi에서 `npx vite preview --outDir <스냅숏> --host --port 5190` 후 폰 브라우저로 접속하고, **홈 화면에 추가**해서 전체 화면으로 실행 (주소창이 화면을 먹으면 판정이 달라짐).
- 원격 디버깅: 안드로이드 = PC 크롬 `chrome://inspect`, 아이폰 = Mac Safari 웹 속성. 콘솔 오류·메모리를 본다.
- 시작 배터리 %, 기기 온도 체감, 시각을 기록.

절차 (체크리스트_모바일.md M0~M24 판정)
1. 아이콘 → 타이틀 시간 재기 (M8)
2. **양손으로 쥐고** 엄지로만 첫 출진까지 (M0, M21). 잘못 누른 횟수를 센다 (M1·M2)
3. 지도 한 손가락 이동 / 두 손가락 확대 / 두 번 탭 / 도시 길게 누르기 (M10)
4. 전투 1회: 작전 회의 → 관전 1배속 → 중간에 홈 버튼 → 10초 뒤 복귀 → 관전이 멈춰 있었는가 (M12)
5. 지도에서 홈 버튼 → 최근 앱 목록에서 앱을 밀어서 종료 → 다시 실행 → 이어지는가 (M13)
6. 전화 걸어 받기 / 화면 잠금 / 알림 당겨 내리기 → 복귀 (M24)
7. 세로로 돌리기 (M14), 안드로이드 뒤로 가기 (M17), 무음 모드 (M18)
8. 비행기 모드로 10분 (M20)
9. 폰 설정 글꼴 크게 → 다시 실행 (M22)
10. 30분 연속 플레이 후 배터리·발열 (M19)
11. 1시간째 웹뷰가 튕기지 않는가, 메모리 (M15)

기록: 기기 모델·OS 버전·웹뷰 버전, 스크린샷(문제 화면), 화면 녹화(제스처 문제는 녹화가 증거).
