# 전장 지도 미리보기

> `validate-scenarios.cjs`가 `battle-scenarios.draft.json`에서 자동으로 그린 지도다. 데이터를 고치면 다시 실행해서 갱신한다.

**지형**: `.` 평지 `%` 숲 `^` 산·고지 `~` 강 `W` 깊은 물 `=` 다리 `,` 여울 `#` 성벽 `G` 성문 `:` 성내·마을 `K` 본성 `C` 영채 `X` 녹각·목책 `D` 군량고·미끼 `H` 둑 `B` 봉화대

**부대**: 숫자 `1~9,0` = 공격 측 / 소문자 `a~k` = 방어 측 / 표 아래 목록 참고. `*`는 연의 모드 전용 부대
