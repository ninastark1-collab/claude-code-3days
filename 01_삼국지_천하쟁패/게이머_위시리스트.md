# 삼국지 덕후 게이머의 위시리스트 📜⚔️

> 친구가 만드는 삼국지 게임(삼국지6 스타일 기반)을 기다리면서 미리 정리해 둔 메모.
> 우선순위: ★★★ 꼭 있어야 함 / ★★ 있으면 확 재밌어짐 / ★ 나중에라도

---

## 1. UI: 이래야 손이 계속 간다

### 메인 화면 (전략 맵)
- ★★★ **중국 전토 지도 한 장에 모든 도시**: 세력별 색이 확 구분되고, 줌인·줌아웃이 부드러워야 함
- ★★★ **도시에 마우스를 올리면 툴팁**: 태수, 병력, 금, 쌀, 민심. 일일이 클릭해서 확인하게 만들면 금방 지침
- ★★★ **상단 고정 바**: 연도·계절, 내 세력 총 금/쌀/병력, 군주 얼굴
- ★★ **"이번 턴 할 일" 알림**: 명령 안 내린 도시, 충성도 낮은 장수, 위협받는 국경 표시
- ★★ **턴 종료 버튼은 크게, 확인창 한 번**: 실수로 넘기면 너무 억울함
- ★ 지도 위에 행군 경로나 화살표 애니메이션

### 장수 정보
- ★★★ **장수 얼굴 초상화**: 삼국지 게임의 생명. 장수가 많아도 얼굴이 있어야 애착이 생김
- ★★★ **능력치 한눈에**: 통솔/무력/지력/정치/매력 막대그래프에 정렬·필터 기능 (무력순, 지력순, 소속 도시별)
- ★★ **열전**: 장수를 클릭하면 연의 속 활약을 2~3줄로. 덕후는 이거 다 읽음
- ★★ 상성·관계 표시: 의형제, 부부, 부자, 원수 (예: 유관장, 여포와 정원·동탁)

### 편의성 (진짜 중요)
- ★★★ **명령은 3클릭 이내**: 도시 → 명령 → 장수 선택이면 끝
- ★★★ **세이브 슬롯 여러 개 + 자동 저장**
- ★★ **위임 기능**: 후방 도시는 "내정 위임"으로 AI에게 맡기기. 후반에 도시가 30개 넘어가면 필수
- ★★ 단축키 (Space = 턴 종료, ESC = 뒤로)
- ★★ 게임 속도와 연출 스킵 옵션

### 분위기
- ★★★ 고풍스러운 한지·묵화 느낌 UI, 붓글씨 폰트(가독성은 지켜서)
- ★★ 계절마다 바뀌는 맵 색감, BGM
- ★★ 명령을 내리면 장수 얼굴과 함께 대사 ("맡겨 주십시오, 주공!")

## 2. 게임 내용: 이게 있어야 삼국지다

### 시나리오 ★★★
연의 흐름대로 여러 시작 시점을 고를 수 있어야 함:
1. 184년 황건적의 난: 영웅들의 시작
2. 190년 반동탁 연합: 군웅할거
3. 200년 관도대전 직전: 조조 대 원소
4. 207년 삼고초려 / 208년 적벽대전
5. 219년 관우의 형주: 삼국정립 절정
6. ★ 가상 시나리오: 모든 장수 랜덤 배치, 신장수로 시작

### 내정
- ★★★ 개간(쌀), 상업(금), 치수(재해 방지), 성벽 보수, 징병, 훈련, 민심 관리
- ★★★ **계절 개념**: 가을에 쌀 수확, 봄에 세금. 메뚜기 떼·홍수·역병 같은 재해 이벤트
- ★★ 장수 능력치가 결과에 확실히 반영돼야 함 (정치 높은 순욱이 하면 확 오르는 쾌감)

### 인사
- ★★★ 인재 탐색, 등용(설득), 포로 처리(등용/석방/처형), 포상으로 충성도 관리
- ★★★ **재야 장수**: 각 지역에 숨어 있는 인재 (와룡·봉추 찾는 재미!)
- ★★ 장수 수명과 사망, 2세 장수 등장 (관흥, 장포, 강유로의 세대교체)
- ★★ 배신과 내응: 충성도 낮으면 다른 세력이 빼감

### 외교 / 계략
- ★★★ 동맹, 정전, 공동 작전, 항복 권고
- ★★ 계략: 이간, 유언비어, 선동, 매복 지시
- ★★ 관직·작위 체계: 공을 세우면 승진하고 능력치나 지휘 병력 상한이 오름

### 역사 이벤트 ★★★ (덕후 심장 저격 포인트)
조건이 맞으면 연의 명장면이 컷신과 대사로 발동:
- 도원결의, 삼고초려, 적벽 화공, 관우 천리행, 장판파, 출사표, 칠종칠금, 읍참마속…
- **if 루트**: 조건에 따라 역사를 바꿀 수 있으면 대박 (관우가 맥성에서 살아남는다든가)

### 엔딩
- ★★★ 천하통일 엔딩 (군주별로 다르면 최고)
- ★ 연의 엔딩 재현

## 3. 전투: 일기토 말고도 이게 필요해

### 전투 기본 ★★★
- **헥스(육각형) 전장**: 평지, 숲, 산, 강, 다리, 성문, 성벽
- **지형 효과**: 숲에서 방어 업, 산은 이동 감소, 강은 수군만
- **부대 = 장수 + 병력**: 장수 능력치가 공격·방어에 반영
- **병량 개념**: 쌀이 떨어지면 사기 폭락하고 탈영. 장기전 긴장감의 핵심
- **사기**: 장수가 죽거나 포위되면 확 떨어짐
- **날씨**: 맑음/비/바람. 바람 방향에 따라 화계가 번지는 방향이 다름

### 병종 ★★★
| 병종 | 특징 |
|---|---|
| 보병 | 균형형, 성 공격에 유리 |
| 기병 | 이동력·돌격 강함, 숲과 산에 약함 |
| 궁병 | 원거리 공격, 근접에 약함 |
| 수군 | 강 위 전투 전용 (적벽!) |
| ★★ 특수병 | 지역 특색: 남만 등갑병, 서량 철기, 연노병 |

가위바위보 같은 상성(창병 > 기병 > 궁병 > 창병)이 있으면 전략성이 확 올라감. (확정판은 설계노트 37장)

### 일기토 ★★★
- 무력 차이만으로 끝나면 재미없음. **선택형**으로: 공격/필살/방어/도주
- 장수 간 **대사 연출**: 관우와 화웅, 장비와 여포, 조운과 문추 같은 특수 대사
- 이기면 적 장수 포로나 퇴각, 아군 사기가 크게 오름
- 거절할 수도 있어야 함 (지력 높은 장수는 거절, 거절하면 사기 감소)

### 일기토 말고 꼭 넣어야 할 것들
- ★★★ **계략(전법)**: 화계, 낙석, 혼란, 매복, 위보(거짓 정보), 동토(동사), 수공. 지력 높은 군사가 빛나는 순간
- ★★★ **군사 조언**: 출진할 때 군사가 "지금 화공을 쓰시면 성공률이 높습니다" 하고 조언. 지력에 따라 정확도가 다름
- ★★★ **공성전**: 성문 파괴, 성벽 오르기, 충차·투석기 같은 공성 병기
- ★★ **설전(舌戰)**: 장수끼리 말싸움. 지력과 매력 대결로 적 사기를 깎음 (제갈량 vs 왕랑!)
- ★★ **전법·특기**: 장수 고유 기술 (관우: 위압, 조운: 돌파, 제갈량: 천기. 이름은 독자적으로, 설계노트 40장)
- ★★ **협공·포위 보너스**: 적을 둘러싸면 공격력 업, 퇴로가 막히면 사기 감소
- ★★ **원군**: 동맹이나 인접 도시에서 지원군이 몇 턴 뒤 도착
- ★★ **야전 → 공성 2단계 전투**: 성 밖에서 이기면 농성전으로
- ★ 진형: 어린진, 학익진 등으로 공격/방어 보정
- ★ 전투 후 결과 화면: MVP 장수, 포로 목록, 획득한 병량과 금

### 전투 편의성
- ★★★ **자동 전투 옵션**: 작은 전투는 넘기고 큰 전투만 직접
- ★★★ 이동 가능 범위와 공격 가능 범위 하이라이트
- ★★ 적 부대 위에 마우스를 올리면 예상 피해량 표시

## 4. 개발 친구에게 하고 싶은 말 💬
1. **처음엔 작게**: 시나리오 1개, 세력 4~5개라도 내정·전투·일기토 한 사이클이 재밌으면 성공
2. **장수 데이터가 생명**: 능력치가 연의 이미지와 맞아야 덕후들이 납득함
3. **AI가 너무 멍청하거나 너무 치사하지 않게**: AI가 동맹을 맺고 배신하는 정도의 "살아있는 느낌"이 핵심
4. 테스트 빌드 나오면 바로 불러줘. 하루 종일 붙잡고 할 준비 돼 있음 🔥
