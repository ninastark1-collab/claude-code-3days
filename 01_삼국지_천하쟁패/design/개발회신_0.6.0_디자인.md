## 1. 확인창 문구 (`src/ui/components/Confirm.tsx` CONFIRM_TEXT)

**원칙**
- 제목은 하려는 행동을 묻는다.
- 본문은 무엇이 없어지는지 구체적으로 말한다.
- 붉은 버튼은 행동 이름, 왼쪽 버튼은 "물러서기"로 쓴다.

```ts
export const CONFIRM_TEXT = {
  quit: { title: '타이틀로 나갈까요?', body: '마지막으로 저장한 뒤의 진행은 남지 않습니다.', cancel: '계속하기', ok: '나가기' },
  overwrite: { title: '이 칸에 덮어쓸까요?', body: '이 칸에 있던 저장은 지워지고, 지금 진행이 그 자리에 저장됩니다.', cancel: '그만두기', ok: '덮어쓰기' },
} as const;
```

**`detail` 줄에 넣을 것** (있으면 훨씬 덜 무섭다)
- quit: `마지막 저장 · 194년 5월 (12분 전)`. 한 번도 저장하지 않았으면 `아직 저장하지 않았습니다`.
- overwrite: 지워질 저장의 요약. `194년 3월 · 유비 · 도시 3`.

**선택 제안 (기능 추가가 필요하니 여유 있을 때)**
- quit 확인창에 세 번째 버튼 `저장하고 나가기`를 금색 주 버튼으로 둔다.
- 순서: [계속하기] [나가기(붉은)] [저장하고 나가기(금색)].

## 2. 설정 › 소리 탭 (DSN-06)

배경음과 효과음을 **같은 모양 두 줄**로 맞춘다. 줄마다 [이름] [켜기/끄기] [크기 막대] [숫자]가 한 줄에 들어간다.

```
배경음   (●)   ━━━━━━━━━●──────  70
효과음   (●)   ━━━━━━━━━━━━●───  85
```

- **효과음 크기:** 효과음에도 크기 막대를 만든다. 지금은 켜기/끄기만 있다. 요청서의 "음악과 효과음 볼륨 분리"는 둘 다 크기를 조절할 수 있어야 끝난다.
- **꺼졌을 때:** 끈 줄은 막대와 숫자를 45% 흐리게 하고 막대를 비활성화한다.
- **미리 듣기:** 효과음 막대에서 손을 떼면 확인음(지금의 짧은 클릭음)을 한 번 낸다. 배경음은 지금 곡이 그대로 커졌다 작아지면 된다.
- **기본값:** 배경음 70, 효과음 85.
- **크기:** 막대 실제 길이 200px, 누르는 높이 44px, 손잡이 지름 24px, 숫자는 고정폭 3자리.

## 3. 폰 설치 안내 페이지 (`public/install.html`)

다듬은 시안: **`design/install-시안.html`**. 그대로 `public/install.html`에 덮어쓰면 된다.

- **스크립트:** 개발이 만든 그대로 두었다. 설치 버튼, 앱 안 브라우저 감지, iOS 안내, 서비스 워커 등록 모두 같다. 요소 id도 전부 같다.
- **바뀐 것은 모양과 문구:**
  - 맨 위에 게임 첫인상: 가로 폰 안의 전장 그림(CSS 그림, 외부 파일 없음)과 제목
  - 게임 소개 세 줄: 연의 시나리오 6개, 무장 726명, 3D 전장
  - "가로로 돌려서 하는 게임" 안내를 그림과 함께 보여 줌
  - 아이폰 설치 순서를 번호 원과 아이콘으로 정리
  - 맨 아래에 버전 표기
- **오프라인:** 외부 글꼴을 쓰지 않고, 기기에 있는 명조체로 제목을 쓴다. 설치 후 인터넷 없이 열어도 모양이 깨지지 않는다.
