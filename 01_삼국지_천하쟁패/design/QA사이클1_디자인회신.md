## DSN-01 세력 색

- 34개 세력 전부 색·무늬·인장을 정했다. 기존 15개 중 11개는 그대로 두고, 원소·공손찬·공손도·이각 4개를 바꿨다.
  - 원소: 너무 어두워 묻혀서 밝힘
  - 공손찬: 공백지 회색과 비슷해서 백마 연청색으로 바꿈
  - 공손도: 조조와 너무 가까움
  - 이각: 동탁과 같은 값이었음
- 같은 시나리오 안의 모든 쌍을 CIEDE2000 색차와 색약 시뮬레이션(Machado 2009, 제1·2·3색맹)으로 검산했다.

  | 시나리오 | 전체 최소 색차 | 인접 최소 색차 |
  |---|---|---|
  | s184 | 19.1 | 25.4 |
  | s190 (23개) | 9.9 (마등/유언, 비인접) | 22.8 |
  | s194 | 12.5 | 21.3 |
  | s200 | 13.0 | 21.3 |
  | s208 | 13.0 | 19.0 |
  | s219 | 15.3 | 33.5 |

- 색약에서 가까워지는 쌍은 무늬를 다르게 해서, 시나리오 안에서 무늬까지 같은 쌍은 0건이다.
- 무늬에 **stripe(가로줄)**가 새로 생겼다. 개발에서 구현이 필요하다.
- 손씨 3대는 같은 주황 계열이다: 손견 #C38241 · 손책 #CD7637 · 손권 #C8642C.

## DSN-02 군주 선택

1. 체급 단어 "강국/중견/약소"는 그대로 좋다. 카드 오른쪽 위 작은 배지로 둔다. 색은 강국 금, 중견 은, 약소 동.
2. 게임 난이도와 역사 이벤트는 군주를 고른 **다음 단계**인 "게임 설정" 화면으로 옮긴다. 한 화면에 둘 거라면 "게임 난이도" 제목과 함께 카드 목록 아래 별도 띠로 둔다.
3. 기본 선택 군주 아래에 추천 이유를 한 줄 넣는다. 예: "처음이라면 추천 — 이야기를 따라가기 좋은 중견 세력".

## DSN-07 엔딩 구성 (다음 시안 예정)

네 장으로 넘기는 구성이다.
1. 統/亡 큰 글자 + 결말 문장
2. 연대기: 연도별 큰 사건 6~8개를 지도 위에 순서대로 표시
3. 통계: 플레이 시간, 점령 도시, 전투 승패, 일기토, 등용 장수
4. 평가와 주요 장수: 칭호 1개 + 활약 장수 3인 초상

마지막에 "타이틀로"와 "이 세력으로 다시"를 둔다.

## DSN-09 겹침 규칙

- 부대 표시(인장·이름·병력·막대)는 장수 머리 위에 하나만 띄운다.
- 화면에서 두 표시가 40px 안으로 겹치면, 화면 아래쪽 표시를 위로 쌓는다(최대 3단).
- 3단을 넘으면 인장만 남긴다. 일기토와 컷인 중에는 모두 숨긴다.

## DSN-11 3D 실패·손실

- **WebGL2가 없을 때:** 3D를 켜지 않고 2D 지도·2D 전장으로 진행한다. 처음 한 번만 "이 기기에서는 3D 화면을 켤 수 없습니다. 같은 내용을 2D로 보여 줍니다"를 띄운다.
- **쓰던 중 컨텍스트를 잃었을 때:**
  - 계산은 멈추지 않는다.
  - "3D 화면을 잠시 잃었습니다" 화면에 [다시 그리기]와 [결과만 보기]를 둔다. 결과만 보기는 양군 병력 막대와 경과 시간을 보여 주는 2D 목록이다.
  - 복구되면 자동으로 3D로 돌아간다.
- 흰 화면이나 검은 화면은 어떤 경우에도 금지다.
- (시안 메모: 시안 페이지 자체는 손실 중 계산도 멈춘다. 게임은 위 규칙대로 계속 계산한다.)

## DSN-12 발열·배터리

- 일시정지, 결과 판, 보고서처럼 움직임이 없는 화면에서는 카메라가 멈추고 입력이 1초 없으면 그리기를 멈춘다. 마지막 화면은 그대로 둔다.
- 백그라운드이거나 화면 밖이면 그리지 않는다. 절약 단계는 30fps 상한이다.
- 10분 연속 관전 기준: 중급 폰에서 배터리 6% 이하 소모, 체감 발열 "따뜻함" 이하.
- 평균 fps가 10초 넘게 목표의 70% 밑이면 화질을 한 단계 자동으로 낮추고 알림을 한 번 띄운다.

## DSN-13 동작 줄이기

- 설정 하나로 켜고 끈다. 켜면 다음을 모두 끈다.
  - 카메라 흔들림
  - 섬광(밝기 번쩍임)
  - 틸트시프트 흐림
  - 자동 줌인(개전 비행, 일기토 근접, 장수 초상을 눌렀을 때 확대, 내정 명령 때 카메라 이동)
- 컷인 띠는 미끄러지지 않고 나타나기만 한다.
- 기기의 "동작 줄이기"가 켜져 있으면 처음부터 켠다.

## 테스터 질문에 대한 답

1. **세력 색 개수:** 34개 전부다. 6개 시나리오에 나오는 모든 세력이고, 한 시나리오 최대 23개(s190)까지 서로 구분된다.
2. **공백지:** 색을 칠하지 않는다(지형 그대로). 국경선도 없다. 도시 표시는 인장 없는 회색 테두리 빈 원 + 이름이다.
3. **배경음악:** BGM은 별도 세션이 준비 중이라 직접 제작인지 라이선스 구매인지는 그 세션과 사용자가 정한다. 디자인 쪽은 볼륨 2개 분리 UI만 맡는다.
4. **새 디자인의 범위:** 모든 화면이다. 비주얼 바이블(색·글꼴·원칙), 모바일 화면 설계 S01~S35(군주 선택·타이틀 포함), 인물·전장 아트, 3D 시안(천하 지도·내정 도시·평원 회전·하비성 공성·일기토 무대)이 범위다. 옮겨지기 전까지는 위 표의 "지금 화면에 반영 요청" 항목을 지금 화면에서 먼저 고친다.
5. **3D 시안을 넘기는 시점:** 1차분은 이미 0.5.0에 옮겨졌다. 앞으로는 시안 버전을 올릴 때마다 개발과 테스터에게 버전과 변경 이력을 먼저 알린다. 이번 회신 기준은 v0.4.5다. 변경 이력의 v0.4.1~0.4.4 중 전투 연출 수정(대열 유지, 일기토 무대 세부, 물 건너기)은 사용자 확인을 기다리는 중이라, 이번 회신의 반영 요청에는 넣지 않았다.
