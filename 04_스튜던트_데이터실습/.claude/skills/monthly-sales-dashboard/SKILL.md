# 월별 매출 통합 → 대시보드

새 달 매출 파일이 들어오면 **모든 달을 다시 합쳐** 통합 엑셀과 대시보드를 새로 만든다. 계산은 전부 `scripts/make_dashboard.py`가 하고, 숫자를 손으로 고치거나 지어내지 않는다.

## 1. 파일 확인

수강생에게 "매출 파일을 확인할게요."라고 알린다.

- 매출 폴더는 실습 루트의 `03_매출데이터`가 기본이다. 실제 이름은 디렉터리를 열거해서 확인한다(한글 정규화 차이 때문에 글자로 경로를 다시 조립하지 않는다).
- 수강생이 새 파일을 채팅에 첨부했거나 다른 곳에 두었으면, 그 파일을 매출 폴더로 **복사**한다. 이름은 `YYYY년_MM월_매출.xlsx` 규칙에 맞춘다. 같은 달 파일이 이미 있으면 덮어쓰기 전에 수강생에게 물어본다.
- 몇 개 파일, 몇 월부터 몇 월까지인지 한 줄로 알린다.

## 2. 실행

실습 폴더 전용 Python으로 실행한다(Windows 예시, 실제 경로에 맞춘다).

```powershell
& '.\.venv\Scripts\python.exe' -X utf8 '.\.claude\skills\monthly-sales-dashboard\scripts\make_dashboard.py' '.\03_매출데이터' '.'
```

결과는 실습 루트에 저장된다. 같은 이름의 지난 결과는 새 결과로 바뀐다.
- `<연도>_매출_통합.xlsx`: 모든 달을 합친 표(시트 `통합데이터`)
- `<연도>_매출_대시보드.html`: 브라우저로 여는 대시보드

## 3. 스크립트가 하는 확인

- 머리글이 달라도(`팀명`·`Department`·`매출(원)` 등) 같은 열로 맞춘다. **처음 보는 머리글이면 멈춘다.** 이때는 파일을 열어 그 열이 무엇인지 확인하고, 확실할 때만 `MAP`에 한 줄 추가한 뒤 다시 실행한다. 모호하면 수강생에게 물어본다.
- 숫자가 아닌 값, `매출 − 비용 ≠ 이익`인 행, 통합 합계와 원본 합계 불일치, 같은 달 파일 두 개, 연도 섞임이 있으면 **파일을 만들지 않고 멈춘다.** 출력된 문제를 쉬운 말로 한 줄씩 알리고, 원본을 마음대로 고치지 않는다.
- 빠진 달이 있거나 완전히 같은 행이 있으면 경고만 하고 계속한다. 이 경고는 수강생에게 꼭 전한다.

## 4. 결과 확인과 보고

1. 출력된 총매출·월별 매출을 확인하고, 새로 들어온 달의 숫자를 한 줄로 알린다(예: "9월 매출은 ○억 원으로 8월보다 ○% 늘었어요.").
2. 대시보드를 브라우저 창에서 열어 차트가 그려지는지, 새 달이 축에 보이는지 확인한다.
3. 수강생에게 결과 파일 두 개와 인사이트 요약 2~3줄을 알린다. 출력에 없는 수치를 덧붙이지 않는다.

## 하지 않는 것

- 원본 매출 파일 수정·삭제
- 확인 안 된 머리글을 추측해서 매핑
- 클로드 아티팩트 대시보드 자동 갱신 — 아티팩트는 계산식에 달 수가 고정된 부분이 있어서, 수강생이 원하면 별도로 새 데이터를 올리고 고정 문구를 손본다.

## 참고
