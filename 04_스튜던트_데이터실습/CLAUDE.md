# 실습 폴더 — Claude 작동 규칙

이 폴더는 **허세임AI 「비개발자를 위한 바이브코딩 입문 with 클로드 코드」 수강생의 실습용**이다.
수강생은 비개발자이고, 서로 다른 회사에서 모였으며, 개발 경험과 컴퓨터 상태가 제각각이다.
실제 실행 환경과 열린 폴더를 확인하고, 수강생이 요청한 단계부터 진행한다.

## 결과물 디자인 — HTML·엑셀·PPT 공통

**수강생이 자기 회사 문서나 템플릿을 주면 그 형식을 먼저 따른다.** 회사 서식이 언제나 우선이고, 아래는 참고할 템플릿이 없을 때 쓰는 기본값이다.

### 기본 팔레트 — 진한 초록 한 가지

흰 바탕에 **진초록 하나만** 강조색으로 쓴다. 여러 색을 늘어놓지 않는 것이 이 팔레트의 핵심이다.

```css
:root {
  /* 대표색 — 이것 하나가 기본이다 */
  --accent: #00462A;         /* 진초록 — 제목, 강조, 결론 */
  --accent-pale: #E8EFEB;    /* 진초록을 아주 연하게 — 표 머리글, 강조 배경 */

  /* 바탕과 글자 */
  --bg-page: #FFFDF1;        /* 아주 연한 크림 — 페이지 배경 */
  --bg-card: #FFFFFF;        /* 카드 배경 */
  --neutral: #B9B9B9;        /* 회색 — 구분선, 비활성 */
  --border: #E1E4E8;
  --text-primary: #1A1A1A;   /* 본문 */
  --text-secondary: #5F6368; /* 보조 설명, 캡션 */

  /* 곁들임색 — 차트에서 계열을 나눌 때만. 전부 합쳐 화면의 10%를 넘기지 않는다 */
  --sub-mint:  #36AE92;
  --sub-lime:  #BCC924;
  --sub-blue:  #45A2BC;
  --sub-coral: #F27367;      /* 감소·주의 표시에 쓰기 좋다 */

  --status-good: #287D4E;
  --status-warn: #925000;
  --status-bad: #B42318;
}
```

역할이 정해져 있다. **검정은 구조(본문·테두리), 진초록은 강조와 결론**이다. 진초록을 본문 색으로 쓰지 않는다.

곁들임색 넷은 **차트에 계열이 여러 개일 때만** 꺼낸다. 계열이 둘이면 진초록과 회색으로 나누고, 셋 이상일 때 민트 → 연두 → 파랑 순으로 더한다. 제목이나 강조 문구에는 쓰지 않는다.

### 디자인 요소 셋

**1. 제목 왼쪽 초록 바** — 섹션 제목을 구분하는 기본 장치. 밑줄보다 덜 시끄럽다.

```css
h2 {
  border-left: 4px solid var(--accent);
  padding-left: 12px;
  color: var(--accent);
}
```

**2. 연한 초록 강조 배경** — 핵심 문장이나 결론 한 덩어리에만. 한 화면에 한 번이면 충분하다.

```css
.callout {
  background: var(--accent-pale);
  border-left: 3px solid var(--accent);
  padding: 12px 16px;
  border-radius: 4px;
}
.key-number { color: var(--accent); font-weight: 700; }
```

**3. 표 머리글과 카드** — 표 머리글은 `--accent-pale` 배경에 `--accent` 글자, 본문 행은 흰 바탕에 `1px solid var(--border)` 가로선만. 세로선은 긋지 않는다. 카드는 `--bg-card` 배경에 연한 테두리, 모서리는 `4px`까지만 둥글린다. 그림자는 쓰더라도 아주 얕게.

### 글꼴

- **Pretendard**가 있으면 쓰고, 없으면 `Malgun Gothic`, `Apple SD Gothic Neo`, `sans-serif`로 넘어간다. **인터넷이 막혀 외부 글꼴을 못 받아도 글이 읽혀야 한다** — 대체 글꼴을 반드시 같이 적는다.
- 제목은 굵기(700)와 크기로 구분한다. 장식용 글꼴을 따로 불러오지 않는다.
- Office 문서(엑셀·PPT·워드)는 웹 글꼴을 못 쓰니 실제 설치된 한글 글꼴을 사용한다.

### 공통 규칙

- 밝은 바탕에 강조색을 **한 군데만** 쓴다. 강한 색으로 화면 전체를 채우지 않는다.
- 색만으로 상태를 구별하지 말고 글자·표시를 함께 쓴다.
- 차트는 같은 지표에 문서 전체에서 같은 색을 유지하고, 범례·단위·데이터 이름을 표시한다. 여러 계열이 필요하면 진초록·회색 농도로 먼저 나누고, 그래도 모자랄 때만 곁들임색을 더한다.
- 표·차트는 읽기 쉬운 크기와 충분한 간격을 유지한다. HTML은 화면 폭이 줄어들어도 숫자와 설명이 잘리지 않게 한다.
- 기존 문서를 갱신하는 과제에서는 요청과 무관한 전체 디자인 변경을 하지 않는다.
- **수강생 회사의 로고를 글자로 조합하거나 AI로 그려서 공식 로고처럼 꾸미지 않는다.** 로고가 없으면 제목에 회사 이름을 적어 진행한다.

## 응답 톤

- 수강생에게는 부드러운 **존댓말**을 쓴다. "확인해드릴게요", "파일에 정리해뒀어요"처럼 짧고 쉬운 말로 설명한다.
- 결론부터 말하고 한 문장에 한 가지를 설명한다. 어려운 단어를 꼭 써야 하면 처음 한 번 풀어 쓴다. 예: 라이브러리 → 엑셀·문서 기능 묶음, 가상환경 → 이 폴더 전용 Python 공간.
- 명령이 실패하면 원인을 단정하거나 긴 오류 원문부터 보여주지 않는다. 확인된 상황과 다음 행동을 한 줄씩 알린다. 재촉하거나 사과를 반복하지 않는다.
- 완료했을 때는 무엇이 바뀌었는지와 결과 파일을 함께 보여준다. 설명만 하고 실제 파일 작업을 끝낸 것처럼 말하지 않는다.

## 진행 상황

명령 실행 전에 무엇을 확인하거나 바꿀지 짧게 알린다. 오래 걸리는 작업은 중간에도 진행 중임을 알린다. 여러 파일을 처리할 때는 확인한 개수와 남은 작업을 알려준다. 끝나면 결과와 확인 방법을 한 줄로 설명한다.

예: "월간 매출 파일을 확인할게요." → "지금까지 3개 파일을 읽었어요." → "통합표를 저장했고, 원본 합계와 맞는지 확인했어요."

수강생이 설치 창·권한 팝업·비밀번호 입력·앱 재시작을 직접 처리해야 하면 **현재 상태, 해야 할 일 하나, 클릭 순서**를 안내한다. 도움이 필요하면 "손 들어서 강사님을 불러주세요"라고 알리고, 해당 조작이 끝났다는 응답을 기다린다.

## 실습 폴더와 자료의 역할

표의 이름은 화면에서 알아보기 위한 표기다. 실제 경로는 디렉터리를 열거해 확인한다. 한글 정규화 차이 때문에 표의 글자로 기존 경로를 무조건 재구성하지 않는다.

| 폴더 | 자료의 역할 |
|---|---|
| `01_다운로드` | 견적·회의록·보고서·계약서 초안이 뒤섞인 다운로드 폴더. 파일 30개가 하위 폴더 없이 그대로 들어 있다. 내용을 읽고 용도·날짜·상태에 따라 정리하는 실습 입력이다. 같은 보고서의 `최종`·`final`·`final_v2` 같은 중복본이 일부러 섞여 있다. |
| `02_데이터클리닝` | 거래처 명단 원본. 같은 회사가 `(주)한빛솔루션`·`한빛솔루션`처럼 다르게 적혀 있고 주소 표기와 이메일도 흔들린다. 중복을 찾아 하나로 합치는 실습 입력이다. |
| `03_매출데이터` | 2026년 1월~8월 매출 파일 8개가 한 달에 하나씩, 하위 폴더 없이 들어 있다. 여러 파일을 하나로 통합하고, 통합 데이터로 대시보드·발표자료를 만드는 실습 입력이다. |

이 자료들은 **교육용 가상 자료**다. 등장하는 회사(미래테크·한빛솔루션·그린에너지 등)와 사람 이름은 모두 지어낸 것이다. 파일을 읽고 확인한 내용만 사용하고, 실제 기업의 실적이나 체결된 계약이라고 설명하지 않는다. 폴더 구성이나 파일이 달라져 있으면 현재 파일을 기준으로 판단한다.

표·보고서의 합계, 단위, 기간, 출처를 원본과 대조한다. 확인되지 않은 수치를 만들지 않는다.

## 이 폴더에 있는 스킬

| 스킬 | 언제 쓰나 |
|---|---|
| `setup-environment` | 첫날 환경 준비. Node.js·Python과 문서 라이브러리를 이 컴퓨터에 맞춰 설치한다. |
| `korean-safe-windows` | 한글 파일명·경로가 깨지거나 "파일이 있는데 못 찾는" 상황. 엑셀·CSV 한글 인코딩도 여기. |
| `huhsame-board` | 실습 결과나 오늘의 각오를 huhsame.com 강의 게시판에 올릴 때. 처음 쓰면 브라우저로 한 번 승인받는다. |
