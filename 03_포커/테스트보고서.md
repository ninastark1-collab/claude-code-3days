# 기억력 포커 — 사용자 입장 테스트 보고서 (2026-11-12)

## 테스트 방법
- 핸드폰 화면 크기(375×812)와 PC 화면(1280×860)에서 실제로 버튼을 눌러가며 플레이
- 직접 카드를 외우고 고른 판, 아무것도 안 고르고 시간을 넘긴 판, 결과 창을 닫고 족보표를 본 뒤 게임판에서 다음 판을 시작하는 흐름까지 확인
- 자동 테스트 58개 (족보 판정, 260만 가지 전체 패 검사, 배분 보정, 최고 족보 찾기) 모두 통과

## 테스트 중 발견해서 바로 고친 것
| 발견한 문제 | 조치 |
|---|---|
| 풀하우스 이름 "J·A 풀하우스"는 J가 3장인지 A가 3장인지 헷갈림 | "J×3 + A×2 풀하우스"로 변경 |
| 결과 카드 순서가 A A J J J 처럼 페어가 트리플보다 앞에 나옴 | 트리플 → 페어 순, A-2-3-4-5 스트레이트는 A를 맨 뒤로 정렬 |
| 2장을 고른 직후 안내 문구가 잠깐 "2장을 고르세요"로 남아 있음 | 고르는 즉시 "선택 완료 · 변경 가능"으로 바뀌게 수정 |
| "골랐어야 할 카드"가 상대가 이미 가져간 카드여도 그냥 표시됨 | "(상대가 가져감)" 표시 추가 |
| 아무것도 안 골라도 자동으로 2장이 뽑혀서, 운 좋으면 플러시로 이김. 왜 이겼는지 알 수 없음 | 결과에 "시간 초과 · 2장 자동 선택" 표시 추가 |
| PC 화면에서 게임판이 화면보다 길어서 스크롤해야 함 | 족보표+게임판 전체가 한 화면에 들어오도록 자동 축소 |

## 스스로 던진 질문과 남은 부족한 점

### 꼭 결정이 필요한 것 (게임 규칙)
1. ~~**시간 초과 시 자동 선택이 공정한가?**~~ → **반영 완료:** 못 고른 장수만큼 '가장 약한 패'가 되는 카드가 자동으로 들어감.
2. ~~**승부가 끝나는 지점이 없음.**~~ → **결정:** 단판 승부. 매 판이 독립된 게임이고 버튼을 눌러야 다음 게임 시작. 위 점수판은 누적 전적. 무승부는 전적에 넣지 않음.
3. **상대가 고른 칸이 실시간으로 보이는 게 맞나?** 지금은 상대가 고른 칸에 "상대" 표시가 즉시 뜸 → 상대가 노리는 카드를 역으로 추리할 수 있음. 눈치 싸움 요소로 둘지, 숨길지 결정 필요.

### 사용하기 불편했던 점
4. **핸드폰에서 외우는 중에 족보표를 열면 카드판 절반이 가려짐.** 외우기 단계에서는 족보표를 자동으로 닫거나, 선택 단계에서만 열리게 하는 게 나음.
5. **외우기 단계에서 공개 카드 3장이 뒷면이라, 처음 하는 사람은 "뭘 외워야 하지?"가 막막함.** 첫 판에 짧은 팁("높은 숫자·같은 무늬 위치를 외우세요") 표시 고려.
6. **카드 위치를 "2행 3열"로 말로 알려주는 건 직관적이지 않음.** 게임판에서는 "최고" 표시로 보이지만 결과 창에 가려져 있음 → 결과 창에 작은 5×4 미니맵으로 위치를 그려주면 더 좋음.
7. **효과음/진동이 거의 없음.** 카드 뒤집기, 남은 5초, 승리 순간에 소리가 있으면 몰입감이 크게 올라감.

### 아직 안 된 것 (원래 계획)
8. **친구와 온라인 대전 미구현.** 지금 상대는 무작위로 고르는 봇이라 실력 대결이 안 됨. 계획 4단계(Supabase 방 코드·실시간 동기화)가 다음 핵심 작업.
9. **배포 안 됨.** 친구 핸드폰에서 열 수 있는 링크가 아직 없음.
10. **실제 핸드폰에서 테스트 안 함.** 브라우저의 핸드폰 화면 흉내로만 확인. 터치감, 글자 크기, 아이폰 하단 홈바 영역은 실제 기기 확인 필요.
11. **글꼴을 인터넷에서 불러옴.** 인터넷이 느리면 처음 몇 초간 기본 글꼴로 보였다가 바뀜.

## 온라인 대전 (2~4명) 점검 (2026-11-12)
- 서버: Supabase 새 프로젝트 `memory-poker`(서울, 무료). 쓰기는 Edge Function `poker`만, 폰은 읽기만
- 서버 직접 호출 테스트: 방장 아닌 사람 시작 차단 / 틀린 비밀키 차단 / 게임 중 참가 차단 / 5번째 참가 차단(최대 4명) / 외우기 전 카드·공개 카드 숨김 / 비밀 테이블 폰에서 읽기 불가 / 3명이 동시에 단계 진행 요청해도 1번만 진행 / 같은 칸 동시 클릭 시 1명만 성공 / 폰에서 전적 직접 수정 불가
- 브라우저 탭 3개(핸드폰 크기)로 실제 대전: 방 만들기 → 초대 링크로 2명 참가 → 대기실 실시간 반영 → 3·2·1 → 외우기(세 탭 같은 카드) → 선택(이름 첫 글자·색으로 표시, 오른쪽 칸 고른 장수 점) → 순위 결과(1~3등, 공동 1등, 시간 초과 표시, 최고 족보 "OO님이 가져감") → 승수 반영
- 새로고침 → 같은 자리로 자동 복귀 / 나가기 → 남은 사람에게 반영, 방장 나가면 다음 사람이 방장 / 방이 지워지면 첫 화면으로
- 360×640 화면에서도 오른쪽 참가자 칸 포함 스크롤 없이 한 화면 (카드 폭 44px)
- 12시간 동안 변화 없는 방은 매시간 자동 삭제
